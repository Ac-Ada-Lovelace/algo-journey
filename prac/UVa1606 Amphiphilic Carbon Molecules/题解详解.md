# UVa 1606 - Amphiphilic Carbon Molecules 详解

## 一、问题理解

### 1.1 题目背景

你有一个工作台，上面散落着 n 个 ACM 纳米颗粒。每个颗粒有两个属性：

- **位置**：二维平面上的坐标 (x, y)
- **类型**：
  - type = 0：**亲水性**（hydrophilic），溶于水，不溶于丙酮
  - type = 1：**疏水性**（hydrophobic），溶于丙酮，不溶于水

### 1.2 操作规则

你需要：

1. **放置一块隔板（ICPC）**：一条直线，将平面分成两个半平面
2. **一侧滴水，另一侧滴丙酮**
3. **溶解规则**：
   - 亲水性 ACM 在**水侧**溶解 ✓
   - 疏水性 ACM 在**丙酮侧**溶解 ✓
   - 在**直线上**的 ACM 也溶解 ✓
   - 其他情况不溶解 ✗

### 1.3 目标

找到一条直线的位置和方向，使得溶解的 ACM 数量**最多**。

---

## 二、问题分析

### 2.1 关键观察

**观察 1：最优直线必过至少一个点**

证明：如果直线不经过任何点，可以平移直线使其经过某个点，而不改变两侧点的分布。

推论：只需枚举**经过某个点**的直线。

**观察 2：问题的本质**

给定一条经过点 i 的直线，它将平面分成三部分：

- **左半平面**：放水
- **直线上**：都溶解
- **右半平面**：放丙酮

溶解数 = (左侧的 type=0 数量) + (直线上的点数量) + (右侧的 type=1 数量)

**观察 3：枚举策略**

- 枚举基准点：O(n)
- 枚举直线方向：需要优化
- 关键：如何高效地枚举所有方向？

## 三、算法演进

### 3.1 暴力算法 O(n³)

```cpp
ans = 0
for 基准点 i (1..n):
    for 方向点 j (1..n):
        if i == j: continue

        cnt = 0
        // 直线经过 i 和 j
        for 每个点 k (1..n):
            用叉积判断 k 在直线的哪一侧
            if 在直线上: cnt++
            else if 在左侧 && type=0: cnt++
            else if 在右侧 && type=1: cnt++

        ans = max(ans, cnt)
```

**复杂度**：O(n³)

- n = 1000 时，10⁹ 次运算，可能 TLE

### 3.2 优化思路

**问题**：内层循环每次都重新统计所有点

**优化**：能否**增量更新**？

答案：可以！用**扫描线算法**。

## 四、扫描线算法

### 4.1 核心思想

固定基准点 i，想象一条经过 i 的直线从某个方向开始**旋转 180°**：

```
        旋转
    ↗   |   ↖
       \|/
    ----i----  直线
       /|\
    ↙   |   ↘
```

在旋转过程中：

- 点会从一侧移到另一侧
- **增量更新**计数，而不是每次重新统计

### 4.2 极角排序

以基准点 i 为原点，计算所有其他点的**极角**（方向角）：

```cpp
angle = atan2(y - yi, x - xi)
```

按极角排序后，点的顺序就是直线旋转时遇到它们的顺序！

```
排序后：
点A(30°) → 点B(60°) → 点C(120°) → 点D(240°) → ...
```

### 4.3 扫描过程

**初始状态**：直线指向某个方向，统计当前的溶解数

**旋转扫描**：

- 直线逆时针旋转
- 每次扫过一个点时，该点从"右侧"移到"左侧"
- 更新计数：
  - 如果是 type=1（疏水）：原来在右侧（丙酮）溶解，现在在左侧（水）不溶解，cnt--
  - 如果是 type=0（亲水）：原来在右侧（丙酮）不溶解，现在在左侧（水）溶解，cnt++

**复杂度**：

- 排序：O(n log n)
- 扫描：O(n)
- 总计：O(n² log n)（枚举 n 个基准点）

## 五、关键技巧：坐标变换

### 5.1 问题的不对称性

原始问题：

- 左侧（水）：type=0 溶解
- 右侧（丙酮）：type=1 溶解

这种**不对称**使得扫描时需要分类讨论。

### 5.2 统一化技巧

**巧妙变换**：对所有 type=1 的点，**坐标取反**！

```cpp
if (p[i].type == 1) {
    x = -(x - xi);
    y = -(y - yi);
}
```

**效果**：

- 原来在右侧的黑点（type=1），变换后相当于在左侧
- 现在问题变成：统计**半平面内的点数**（所有点都在左侧溶解）

**图示**：

```
原坐标系：
      白点A(1,2)
         |
    -----|-----基准点
         |
      黑点B(3,4)

变换后：
      白点A(1,2)
         |
    -----|-----基准点
         |
  黑点B'(-3,-4)

现在 A 和 B' 都是"左侧溶解"！
```

## 六、双指针技巧

### 6.1 半平面的定义

经过基准点的一条直线将平面分成两个半平面。

我们维护一个**半平面**（180° 的扇形区域）：

```
        半平面（180°）
           ↗ R边界
          /
         /
    基准点-------
         \
          \
           ↘ L边界
```

### 6.2 双指针维护

```cpp
L: 半平面的起始边界
R: 半平面的终止边界
ans: [L, R) 区间内有多少个点
```

**关键函数**：判断从 L 到 R 是否 ≤ 180°

```cpp
bool flag(Point L, Point R) {
    return L.x * R.y - L.y * R.x >= 0;  // 叉积 ≥ 0
}
```

**叉积的几何意义**：

- `> 0`：R 在 L 的左侧（逆时针方向）
- `= 0`：R 和 L 同向
- `< 0`：R 在 L 的右侧（顺时针方向）

如果叉积 ≥ 0，说明从 L 逆时针转到 R 的角度 ≤ 180°。

### 6.3 扫描流程

```cpp
L = 1, R = 1, ans = 2  // 初始：基准点 + 即将加入的点

while (L <= tot) {
    // 步骤1：扩展 R
    if (R == L)
        R = (R % tot) + 1, ++ans

    while (R != L && flag(a[L], a[R]))
        R = (R % tot) + 1, ++ans

    // 此时 [L, R) 是一个 ≤180° 的半平面

    // 步骤2：移动 L
    ++L
    --ans  // L 移出半平面

    // 步骤3：记录答案
    maxn = max(ans, maxn)  // 在 L 移动后更新
}
```

**详细解释**：

**初始化**：

- L 指向极角最小的点
- R 从 L 开始，逐步扩展
- ans = 2（基准点本身 + 第一个点）

**扩展 R**：

```cpp
while (R != L && flag(a[L], a[R]))
    R = (R % tot) + 1, ++ans
```

- 只要半平面角度 ≤ 180°，就继续加点
- R 是循环的：到达末尾后回到开头（极角的周期性）

**移动 L**：

```cpp
++L
--ans
```

- L 右移，相当于半平面顺时针旋转
- 移出一个点，ans 减 1

**为什么正确？**

每次 L 移动时：

1. [L, R) 始终维护一个 ≤180° 的半平面
2. 通过移动 L，我们遍历了所有可能的半平面方向
3. 每个方向的答案都被记录

**为什么在 L 移动后更新答案？**

这是关键细节！当 L 移动后：
- 原来的 a[L] 点从半平面中移出
- ans-- 后，ans 表示的是**除了基准点和当前边界点外**的半平面内点数
- 这才是真正的"半平面内的点数"，因为边界上的点（a[L]）已经被移除

理解：初始 ans=2 是"基准点 + 第一个要加入的点"，在扫描过程中 ans 一直多计了 1（边界点），只有在 L 移动后，ans 才是准确的半平面内点数。

### 6.4 循环数组

为什么 R 要循环？

```
极角排序后：
0° → 30° → 60° → ... → 330° → (回到 0°)
```

极角是**周期的**：360° = 0°

所以当 R 到达数组末尾时，要回到开头：

```cpp
R = (R % tot) + 1
```

**例子**：

```
tot = 6
极角：30° 60° 120° 180° 240° 300°
索引：1   2   3    4    5    6

当 L=5, R=6:
  扩展 R: 6 → 1 (循环) → 2
  如果 flag(a[5], a[1]) 成立，继续扩展
```

## 七、完整算法流程

### 7.1 伪代码

```
ans = 0

for 基准点 i = 1 to n:
    tot = 0

    // 坐标变换
    for 点 j = 1 to n:
        if j == i: continue

        dx = p[j].x - p[i].x
        dy = p[j].y - p[i].y

        // 关键：type=1 的点取反
        if p[j].type == 1:
            dx = -dx
            dy = -dy

        a[++tot] = {dx, dy, atan2(dy, dx)}

    // 极角排序
    sort(a[1..tot])

    // 双指针扫描
    L = 1, R = 1, cnt = 2

    while L <= tot:
        if R == L:
            R = (R % tot) + 1, cnt++

        while R != L && flag(a[L], a[R]):
            R = (R % tot) + 1, cnt++

        L++, cnt--
        ans = max(ans, cnt)  // 注意：在 L 移动后更新答案

return ans
```

### 7.2 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    int x, y, type;
} p[1010];

struct Polar {
    double x, y, angle;
} a[1010];

bool cmp(Polar a, Polar b) {
    return a.angle < b.angle;
}

bool flag(Polar L, Polar R) {
    return L.x * R.y - L.y * R.x >= 0;
}

int solve(int pos, int n) {
    int tot = 0;

    // 坐标变换
    for (int i = 1; i <= n; i++) {
        if (i == pos) continue;

        double dx = p[i].x - p[pos].x;
        double dy = p[i].y - p[pos].y;

        // 黑点取反
        if (p[i].type == 1) {
            dx = -dx;
            dy = -dy;
        }

        a[++tot] = {dx, dy, atan2(dy, dx)};
    }

    sort(a + 1, a + tot + 1, cmp);

    // 双指针
    int L = 1, R = 1, ans = 2, maxn = 0;

    while (L <= tot) {
        if (R == L)
            R = (R % tot) + 1, ans++;

        while (R != L && flag(a[L], a[R]))
            R = (R % tot) + 1, ans++;

        L++;
        ans--;
        maxn = max(ans, maxn);  // 注意：在 L 移动后更新
    }

    return maxn;
}

int main() {
    int n;
    while (cin >> n && n) {
        for (int i = 1; i <= n; i++) {
            cin >> p[i].x >> p[i].y >> p[i].type;
        }

        int ans = 0;
        for (int i = 1; i <= n; i++) {
            ans = max(ans, solve(i, n));
        }

        cout << ans << endl;
    }
    return 0;
}
```

## 八、算法正确性证明

### 8.1 坐标变换的正确性

**命题**：黑点取反后，问题等价于"统计半平面内的点数"

**证明**：

原问题：

- 点 P 在左侧，type=0 → 溶解
- 点 P 在右侧，type=1 → 溶解

变换后：

- 白点 P(x,y) → P(x,y)，在左侧 → 溶解 ✓
- 黑点 Q(x,y) → Q'(-x,-y)

对于黑点 Q：

- 原来在右侧（相对于直线 L）
- Q' 在左侧（相对于直线 L）
- 因为 Q' 的坐标是 Q 关于原点的对称点

```
直线 L 经过原点（基准点）

原来：
    L
    |  Q(右侧)
----|----
    |

变换后：
    L
    |
----|----
  Q'|  (Q' 在左侧)
```

所以 Q 在右侧溶解 ⟺ Q' 在左侧（变换后）

### 8.2 双指针的正确性

**命题**：双指针遍历了所有可能的半平面方向

**证明**：

1. **不变式**：任何时刻，[L, R) 构成一个 ≤180° 的半平面

2. **完备性**：
   - L 从 1 遍历到 tot
   - 对每个 L，R 扩展到最大可能位置
   - 覆盖了所有以 a[L] 为边界的半平面

3. **无遗漏**：
   - 任何最优半平面必定有一个边界对准某个点
   - 当 L 移动到该点时，该半平面被考虑

## 九、复杂度分析

### 9.1 时间复杂度

```
for i = 1 to n:           // O(n)
    坐标变换: O(n)
    排序: O(n log n)
    双指针: O(n)          // L 和 R 各移动 O(n) 次

总复杂度: O(n × n log n) = O(n² log n)
```

n = 1000: 约 10^7 次运算，完全可以接受

### 9.2 空间复杂度

O(n)：存储变换后的点

## 十、易错点总结

### 10.1 坐标变换易错

**错误写法**：

```cpp
if (type == 1) {
    x = -x;  // ✗ 错！应该先平移再取反
    y = -y;
}
```

**正确写法**：

```cpp
dx = p[i].x - p[pos].x;  // 先平移到以 pos 为原点
dy = p[i].y - p[pos].y;

if (type == 1) {
    dx = -dx;  // ✓ 再取反
    dy = -dy;
}
```

### 10.2 循环数组边界

**错误写法**：

```cpp
R = R + 1;
if (R > tot) R = 1;  // ✗ 可能越界
```

**正确写法**：

```cpp
R = (R % tot) + 1;  // ✓ 正确的循环
```

### 10.3 初始值设置

**错误**：

```cpp
ans = 1;  // ✗ 忘记直线上的点
```

**正确**：

```cpp
ans = 2;  // ✓ 基准点 + 直线上至少还有一个点
```

### 10.4 叉积判断

**注意**：

```cpp
cross = L.x * R.y - L.y * R.x

cross > 0:  R 在 L 左侧（逆时针）
cross = 0:  R 和 L 共线
cross < 0:  R 在 L 右侧（顺时针）

flag 函数用 >= 0：允许 ≤180°
```

## 十二、总结

### 12.1 算法精髓

1. **问题转化**：平面分割 → 半平面统计
2. **坐标变换**：不对称问题 → 对称问题
3. **极角排序**：离散化旋转方向
4. **双指针**：增量更新，避免重复计算
