【题目概览】

- 给定一根长度为 l 的木棒，需要在指定的位置做 n 次切割，每次只能切一刀，切割费用等于当前被切段的长度。不同切割顺序费用不同，要求出最小总费用。

【输入格式：逐句解释】

- 输入包含多组测试用例。每组第一行是正数 l，表示木棒长度（l < 1000）。若 l = 0，表示输入结束。
- 第二行是整数 n（n < 50），表示需要切割的位置数量。
- 第三行包含 n 个严格递增的正数 ci（0 < ci < l），表示切割位置。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：l
   - 含义：木棒长度
   - 类型：正整数
   - 取值范围：l < 1000
   - 数据保证：l = 0 表示输入结束，不作为测试数据

2. 第 2 行：n
   - 含义：切割位置数量
   - 类型：整数
   - 取值范围：n < 50
   - 数据保证：题面未给其他保证

3. 第 3 行：c1 c2 ... cn
   - 含义：切割位置（距离木棒一端的距离）
   - 类型：正整数序列，严格递增
   - 取值范围：0 < ci < l
   - 特别说明：位置按升序给出

多组输入：

- 是否多组：是
- 每组格式：三行（l；n；n 个位置）
- 终止条件：遇到 l = 0 的用例
- 终止行是否需要处理：否（l=0 的用例不做计算）

隐含条件 / 数据保证：

- 切割仅在给定的 ci 位置，不得额外添加位置（题面含义）。
- 每次费用等于当前被切段长度（PDF 明确）。
- ci 严格递增且在 (0, l) 之间（PDF 明确）。

【输出格式】

- 对每个测试用例输出一行：`The minimum cutting is X.` 其中 X 为最小总费用，句末有句点。

【样例输入输出（完整引用 + 输入部分解释）】

样例输入：

```
100
3
25 50 75
10
4
4 5 7 8
0
```

样例输出：

```
The minimum cutting is 200.
The minimum cutting is 22.
```

输入解释：

- 第 1 组：棒长 100，需要在 25、50、75 处切割。
- 第 2 组：棒长 10，需要在 4、5、7、8 处切割。
- `0` 表示输入结束。

【关键假设 / 陷阱】

- l=0 仅作终止，不参与计算。
- 费用定义基于当前被切段的长度，每次只切一刀；顺序会影响总费用。
- 切割点严格递增，无重复；不要求输出切割顺序，只要给出最小费用。
- 输出格式需精确匹配题面字符串与标点。

【解法提示（可选）】

- 区间 DP：添加端点 0 和 l，排序位置；`dp[l][r]` 为在区间 (pos[l], pos[r]) 全部内部切点完成的最小费用，转移枚举内部切点 k，加上区间长度。
- 状态数 O(n^2)，转移 O(n)，总体 O(n^3)；n<50 可接受。
