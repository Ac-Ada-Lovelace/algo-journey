【题目概览】
- 你要帮助主人把偶数个客人分成两队，各占一半，并给出一个字符串 S，让主人只需按字典序将客人名字与 S 比较，就能判断归属：名字小于等于 S 的一半、大于 S 的一半。需要让 S 的长度尽可能短；若有多种最短长度，取字典序最小的方案。名字在每个测试用例中保证互不相同。

【输入格式：逐句解释】
- 输入可能包含多组测试。
- 每个测试用例第一行是一个偶数整数 n（2 ≤ n ≤ 1,000）。
- 接下来 n 行，每行是一个客人名字。每个名字由全大写字母组成，且长度不超过 30。
- 当读到单独一行的数字 0 时，表示输入结束，不再有后续测试用例。

【输入格式（结构化摘要）——字段清单】

字段顺序：
1. 第 1 行：n
   - 含义：当前测试用例的客人数，且需被分成两队。
   - 类型：偶数整数
   - 取值范围：2 ≤ n ≤ 1000
   - 数据保证：n 为偶数
2. 第 2 行至第 n+1 行：name_i
   - 含义：第 i 个客人的名字（在本用例中各不相同）
   - 类型：仅含大写英文字母的字符串
   - 取值范围：长度 ≤ 30；字母范围 A–Z
   - 特别说明：同一测试用例内名字互不重复（来自题面描述“unique names”）

多组输入：
- 是否多组：是
- 每组格式：如上，先 n，后 n 行名字
- 终止条件：读到单独的“0”行
- 终止行是否需要处理：否，终止行仅用于结束，不代表一个用例

隐含条件 / 数据保证：
- n 为偶数（题面明确）
- 名字全为大写字母，长度 ≤ 30（题面明确）
- 名字在同一用例内不重复（题面明确）

【输出格式】
- 对每个测试用例，输出一行最短可能的字符串 S，使得恰有一半名字按字典序小于等于 S，另一半大于 S；若存在多条同最短长度的字符串，输出其中字典序最小的一个。输出需全部大写。

【样例输入输出（完整引用 + 输入部分解释）】

Sample Input
```
4
FRED
SAM
JOE
MARGARET
2
FRED
FREDDIE
2
JOSEPHINE
JERRY
2
LARHONDA
LARSEN
0
```

Sample Output
```
K
FRED
JF
LARI
```

样例说明：
- 用例 1：n=4，名字为 FRED, SAM, JOE, MARGARET。
- 用例 2：n=2，名字为 FRED, FREDDIE。
- 用例 3：n=2，名字为 JOSEPHINE, JERRY。
- 用例 4：n=2，名字为 LARHONDA, LARSEN。
- 行“0”仅为结束标记，不构成用例。PDF 中分页符出现在样例之间，实际输入不包含该控制字符。

【关键假设 / 陷阱】
- S 不一定等于某个名字，也可位于两个名字之间；必须保证恰好一半名字小于等于 S，另一半大于 S。
- 要求 S 尽量短；长度优先级高于字典序，只有在长度相同才比较字典序。
- 输出必须是大写字符串，不能混入小写或空格。
- 多组输入直到 0，不能漏掉中间用例。

【解法提示（可选）】
- 将名字排序，目标 S 需要落在中间两个名字之间（或等于其中一个），可基于中间的两个字符串构造最短分隔字符串，并在同长度下选字典序最小。***
