# 巨人与鬼问题 - 质子流版本 (Giants and Ghosts - No Crossing Lines)

## Problem Description

在平面上有 n 个巨人和 n 个鬼，没有三者在同一条直线上。每个巨人需要选择一个不同的鬼，向其发送质子流消灭它。质子流由巨人发射，沿直线行进，遇到鬼后消失。

**关键约束**：由于质子流交叉是很危险的，所有质子流经过的线段不能有交点。

**问题**：请设计一种给巨人和鬼配对的方法，使得所有连线不相交。

## Input

- 第一行：整数 n (1 ≤ n ≤ 1000)
- 接下来 n 行：每行两个整数 gx, gy，表示第 i 个巨人的坐标
- 接下来 n 行：每行两个整数 dx, dy，表示第 i 个鬼的坐标

保证没有三点共线。

## Output

输出 n 行，每行一个整数，第 i 行表示第 i 个巨人配对的鬼的编号（从 1 到 n）。

要求输出的配对方案中，任意两条连线不相交。

## Sample Input
```
3
0 0
2 0
1 2
0 1
2 1
1 -1
```

## Sample Output
```
1
2
3
```

## Notes

**问题特点**：
- 这是一个**平面几何 + 分治**问题
- 需要找到一个无交叉的完美匹配
- 经典的算法是**递归分治法**

**核心思想**：
1. 找到一个分割线，将平面分为两部分
2. 递归处理左右两部分
3. 合并时保证跨越分割线的连线不相交

**关键引理**：
对于任意 n 个巨人和 n 个鬼的点集（无三点共线），总是存在一种无交叉的完美匹配。

**算法提示**：

### 方法1：递归分治（推荐）

1. **递归基**：n=1 时，唯一的巨人配对唯一的鬼
2. **分治步骤**：
   - 找到一条竖直线（或其他方向），将所有点分为左右两部分
   - 确保左边有 k 个巨人和 k 个鬼，右边有 n-k 个巨人和 n-k 个鬼
   - 递归处理左右两部分
   - 由于分治线的选择保证了左边的点不会和右边的点配对，因此不会产生交叉

### 方法2：基于凸包的贪心法

1. 找到所有点的凸包
2. 从凸包上选择一个巨人 G 和一个鬼 g，使得线段 Gg 不与其他点的连线相交
3. 连接 G 和 g，将剩余点分为两个子问题
4. 递归处理

### 方法3：扫描线 + 排序

1. 对所有巨人按 x 坐标排序
2. 对所有鬼按 x 坐标排序
3. 按顺序配对（第 i 个巨人配第 i 个鬼）
4. 可以证明这种配对不会交叉

## 算法复杂度

- **分治法**：T(n) = 2T(n/2) + O(n) = O(n log n)
- **排序法**：O(n log n)

## Proof Sketch (排序法的正确性)

**定理**：将巨人和鬼分别按 x 坐标排序后按顺序配对，得到的匹配是无交叉的。

**证明**：
假设存在两条线段 (Gi, gi) 和 (Gj, gj) 相交，不失一般性设 i < j。

由于按 x 坐标排序：
- Gi.x ≤ Gj.x
- gi.x ≤ gj.x

如果两条线段相交，有两种情况：
1. Gi 在 Gj 左边，gi 在 gj 右边 → 矛盾（gi.x ≤ gj.x）
2. Gi 在 Gj 右边，gi 在 gj 左边 → 矛盾（Gi.x ≤ Gj.x）

因此不存在交叉。■

## Example Illustration

```
巨人：G1(0,0), G2(2,0), G3(1,2)
鬼：  g1(0,1), g2(2,1), g3(1,-1)

按 x 坐标排序：
巨人：G1(0,0) < G3(1,2) < G2(2,0)
鬼：  g1(0,1) < g3(1,-1) < g2(2,1)

配对：
G1 → g1
G3 → g3
G2 → g2

可以验证这三条线段不相交。
```

## 扩展思考

1. **如果有障碍物怎么办？**
   - 需要使用计算几何中的可见性图
   - 问题变成带约束的完美匹配

2. **如果要求总连线长度最小？**
   - 变成最小权完美匹配问题
   - 使用匈牙利算法或 Kuhn-Munkres 算法
   - 时间复杂度 O(n³)

3. **如果允许少量交叉（最多 k 个交叉点）？**
   - 变成优化问题，NP-hard
   - 需要近似算法或启发式搜索
