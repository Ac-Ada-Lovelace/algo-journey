# 最大连续和问题 (Maximum Subarray Sum)

## 📌 问题描述

给定一个整数数组，找出和最大的连续子数组，返回这个最大和。

**例子**：

```
数组: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
最大连续和: 6
对应子数组: [4, -1, 2, 1]
```

---

## 🔄 算法优化历程

### 方法 1：暴力枚举 - O(n³)

```cpp
int maxSum = INT_MIN;
for (int i = 0; i < n; i++) {           // 枚举起点
    for (int j = i; j < n; j++) {       // 枚举终点
        int sum = 0;
        for (int k = i; k <= j; k++) {  // 计算 [i, j] 的和
            sum += a[k];
        }
        maxSum = max(maxSum, sum);
    }
}
```

**缺点**：三层循环，时间复杂度 O(n³)

---

### 方法 2：前缀和优化 - O(n²)

**核心思想**：`sum[i...j] = prefix[j] - prefix[i-1]`

```cpp
// 预处理前缀和
prefix[0] = 0;
for (int i = 1; i <= n; i++) {
    prefix[i] = prefix[i-1] + a[i];
}

int maxSum = INT_MIN;
for (int i = 1; i <= n; i++) {          // 枚举起点
    for (int j = i; j <= n; j++) {      // 枚举终点
        int sum = prefix[j] - prefix[i-1];
        maxSum = max(maxSum, sum);
    }
}
```

**优化**：去掉一层循环，时间复杂度 O(n²)

---

### 方法 3：分治法 - O(n log n)

**核心思想**：把数组从中间分成两半，最大和要么在左半部分，要么在右半部分，要么跨越中点。

#### 思路分析

假设数组 `a[l...r]`，中点是 `m = (l + r) / 2`：

```
[左半部分] | [右半部分]
  l...m       m+1...r
           ↑
         中点
```

最大连续和有三种可能：

1. **完全在左半部分** `[l...m]`
2. **完全在右半部分** `[m+1...r]`
3. **跨越中点** - 从中点向两边扩展

#### 代码实现

```cpp
// 计算跨越中点的最大和
int maxCrossingSum(vector<int>& a, int l, int m, int r) {
    // 从中点向左扩展，找左半部分的最大和
    int leftSum = INT_MIN;
    int sum = 0;
    for (int i = m; i >= l; i--) {
        sum += a[i];
        leftSum = max(leftSum, sum);
    }

    // 从中点+1向右扩展，找右半部分的最大和
    int rightSum = INT_MIN;
    sum = 0;
    for (int i = m + 1; i <= r; i++) {
        sum += a[i];
        rightSum = max(rightSum, sum);
    }

    // 跨越中点的最大和 = 左边最大 + 右边最大
    return leftSum + rightSum;
}

// 分治求解最大连续和
int maxSubArray(vector<int>& a, int l, int r) {
    // 基础情况：只有一个元素
    if (l == r) {
        return a[l];
    }

    int m = (l + r) / 2;

    // 递归求三种情况
    int leftMax = maxSubArray(a, l, m);        // 左半部分
    int rightMax = maxSubArray(a, m + 1, r);   // 右半部分
    int crossMax = maxCrossingSum(a, l, m, r); // 跨越中点

    // 返回三者中的最大值
    return max({leftMax, rightMax, crossMax});
}

// 调用方式
int result = maxSubArray(a, 0, n - 1);
```

#### 图解示例

```
数组: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
      └─────────┬─────────┘
            分成两半

第一次分：
左: [-2, 1, -3, 4]    右: [-1, 2, 1, -5, 4]
中点: 4 和 -1 之间

第二次分（左半）：
左左: [-2, 1]         左右: [-3, 4]
                      ↑
                  找到局部最大 4

第二次分（右半）：
右左: [-1, 2, 1]      右右: [-5, 4]
      ↑
  找到局部最大 2

合并时检查跨越中点的情况...
```

#### 跨越中点的详细计算

以 `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` 为例，中点在索引 4（值为 -1）：

**从中点向左扫描**：

```
位置:  3    2    1    0
值:    4   -3    1   -2
累加:  4    1    2    0
最大: 4 (取位置 3)
```

**从中点+1向右扫描**：

```
位置:  5    6    7    8
值:    2    1   -5    4
累加:  2    3   -2    2
最大: 3 (取位置 5-6)
```

**跨越中点的最大和**：4 + 3 = 7（实际上不是全局最大）

#### 递归树

```
                 maxSubArray([...])
                 /        |        \
                /         |         \
         左半最大      跨中点最大    右半最大
            /                          \
           /                            \
      继续分治...                    继续分治...
```

时间复杂度分析：

- 每层需要 O(n) 时间（计算跨越中点）
- 递归深度 O(log n)
- 总复杂度：O(n log n)

#### 为什么分治法"很扯淡"？

虽然思路直观，但实际上：

1. **性能不如 Kadane**：O(n log n) vs O(n)
2. **代码复杂**：需要额外的 `maxCrossingSum` 函数
3. **空间开销**：递归调用栈 O(log n)

**但是**，分治法的价值在于：

- ✅ 展示了分治思想的应用
- ✅ 思路清晰，容易理解"分解-递归-合并"
- ✅ 为其他真正需要分治的问题打基础（如归并排序）

**结论**：理解分治思想很重要，但解决最大连续和问题时，永远用 Kadane！

### 方法 4：Kadane 算法（贪心）- O(n) ⭐

这是**最优解**！

#### 核心思路

**站在每个位置，你要做一个决定：**

> "要不要把当前元素加入之前的连续子数组？"

**决策规则：**

- 如果之前的和是**正数** → 有价值，继续累加
- 如果之前的和是**负数** → 是负担，抛弃它，重新开始

#### 代码实现（写法 1）

```cpp
int maxSubArray(vector<int>& a) {
    int maxSum = INT_MIN;    // 全局最大和
    int currentSum = 0;      // 当前子数组的和

    for (int i = 0; i < a.size(); i++) {
        currentSum += a[i];  // 加上当前元素

        // 更新全局最大
        maxSum = max(maxSum, currentSum);

        // 如果当前和是负数，抛弃它
        if (currentSum < 0) {
            currentSum = 0;
        }
    }

    return maxSum;
}
```

#### 代码实现（写法 2 - 更简洁）

```cpp
int maxSubArray(vector<int>& a) {
    int maxSum = INT_MIN;
    int currentSum = 0;

    for (int i = 0; i < a.size(); i++) {
        // 选择：要么继续累加，要么重新开始
        currentSum = max(a[i], currentSum + a[i]);
        maxSum = max(maxSum, currentSum);
    }

    return maxSum;
}
```

两种写法**等价**：

- 写法 1：更直观，"负数就清零"
- 写法 2：更简洁，"选更大的"

## 🎯 Kadane 算法详细推演

用例子一步步理解：

```
数组: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
索引:  0   1   2  3   4  5  6   7  8
```

| 步骤 | i   | a[i] | 决策       | currentSum | maxSum | 说明                        |
| ---- | --- | ---- | ---------- | ---------- | ------ | --------------------------- |
| 1    | 0   | -2   | 第一个元素 | -2         | -2     | 初始状态                    |
| 2    | 1   | 1    | 重新开始   | 1          | 1      | -2是负担，扔掉              |
| 3    | 2   | -3   | 继续累加   | -2         | 1      | 1+(-3)=-2，虽然变小但比-3好 |
| 4    | 3   | 4    | 重新开始   | 4          | 4      | -2是负担，扔掉              |
| 5    | 4   | -1   | 继续累加   | 3          | 4      | 4+(-1)=3                    |
| 6    | 5   | 2    | 继续累加   | 5          | 5      | 3+2=5                       |
| 7    | 6   | 1    | 继续累加   | 6          | 6      | 5+1=6 ⭐最优解              |
| 8    | 7   | -5   | 继续累加   | 1          | 6      | 6+(-5)=1                    |
| 9    | 8   | 4    | 继续累加   | 5          | 6      | 1+4=5                       |

**最终答案**：6，对应子数组 `[4, -1, 2, 1]`

---

## 💡 关键洞察

### 为什么负数要抛弃？

假设你走到位置 i，之前的累积和是 `-5`：

- 如果下一个元素是 `3`
  - 方案 A：`-5 + 3 = -2`（继续累加）
  - 方案 B：`3`（重新开始）
  - 显然方案 B 更好！

**结论**：负数对后续的和只会拖后腿，不如抛弃。

### 动态规划视角

```cpp
dp[i] = 以位置 i 结尾的最大连续和

状态转移：
dp[i] = max(a[i], dp[i-1] + a[i])
       ↑        ↑
    重新开始   继续累加
```

Kadane 算法实际上是 DP 的**空间优化版本**（只用一个变量记录）。

```
currentSum 的变化：
-2 → 扔 → 1 → -2 → 扔 → 4 → 3 → 5 → 6 → 1 → 5

maxSum 的变化：
-2 → 1 → 1 → 4 → 4 → 5 → 6 → 6 → 6

```

## 📝 如何记录具体的子数组？

如果需要输出具体是哪个子数组，可以记录起点和终点：

```cpp
int maxSubArray(vector<int>& a, int& start, int& end) {
    int maxSum = INT_MIN;
    int currentSum = 0;
    int tempStart = 0;  // 临时起点

    for (int i = 0; i < a.size(); i++) {
        currentSum += a[i];

        if (currentSum > maxSum) {
            maxSum = currentSum;
            start = tempStart;  // 记录起点
            end = i;            // 记录终点
        }

        if (currentSum < 0) {
            currentSum = 0;
            tempStart = i + 1;  // 下次重启的起点
        }
    }

    return maxSum;
}
```

## ❓ 常见问题

### Q1: 如果数组全是负数怎么办？

```cpp
数组: [-5, -2, -8, -1]
答案: -1 (返回最大的负数)
```

Kadane 算法能正确处理，因为 `maxSum` 会记录遇到的所有值中的最大值。

### Q2: 空数组怎么处理？

根据题目要求：

- 如果允许空子数组，返回 0
- 如果不允许，返回错误或特殊值

### Q3: 两种写法有什么区别？

**写法 1（清零）**：

```cpp
currentSum += a[i];
if (currentSum < 0) currentSum = 0;
```

**写法 2（取最大）**：

```cpp
currentSum = max(a[i], currentSum + a[i]);
```

**区别**：

- 写法 1 更容易理解"重启"的概念
- 写法 2 更符合 DP 的状态转移方程
- 两者**完全等价**

## 🎯 时间复杂度总结

| 方法     | 时间复杂度 | 空间复杂度 | 优点     | 缺点         |
| -------- | ---------- | ---------- | -------- | ------------ |
| 暴力枚举 | O(n³)      | O(1)       | 简单直接 | 太慢         |
| 前缀和   | O(n²)      | O(n)       | 比暴力快 | 还是慢       |
| Kadane   | O(n)       | O(1)       | 最优解   | 需要理解     |
| 分治法   | O(n log n) | O(log n)   | 思想清晰 | 代码复杂且慢 |

**结论**：实际使用永远选 Kadane 算法！
