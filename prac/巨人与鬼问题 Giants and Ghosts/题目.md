# 巨人与鬼问题 (Giants and Ghosts Problem)

## Problem Description

有 n 个巨人和 n 个鬼要排成一圈（坐在圆桌旁），要求满足以下条件：

1. **巨人和鬼必须交替排列**（相邻两个位置不能都是巨人或都是鬼）
2. **每个巨人的左右两侧各有一个鬼**
3. **每个鬼的左右两侧各有一个巨人**

给定 n，要求输出一种合法的排列方案。

## Input

一个整数 n (1 ≤ n ≤ 8)，表示有 n 个巨人和 n 个鬼。

## Output

输出一个长度为 2n 的序列，表示围成一圈的排列方案：
- 用 `G` 表示巨人 (Giant)
- 用 `g` 表示鬼 (ghost)

输出时可以从任意位置开始，只要满足交替排列即可。

## Sample Input 1
```
1
```

## Sample Output 1
```
G g
```

解释：1个巨人和1个鬼，排成：G-g（首尾相连）

## Sample Input 2
```
2
```

## Sample Output 2
```
G g G g
```

解释：2个巨人和2个鬼，排成：G-g-G-g（首尾相连）

## Sample Input 3
```
4
```

## Sample Output 3
```
G g G g G g G g
```

## Notes

**问题特点**：
- 这是一个**环形排列**问题
- 总共 2n 个位置，n 个巨人，n 个鬼
- 由于要求交替排列，奇数位置全是一种，偶数位置全是另一种

**简化理解**：
其实这个问题的解非常简单：只要让巨人占据所有奇数位置（或偶数位置），鬼占据所有偶数位置（或奇数位置）即可。

**为什么叫"分治"问题？**
实际上，这个问题本身很简单，但它可以作为理解**环形分治**的入门例题。如果扩展到更复杂的约束（比如某些巨人之间不能相邻，某些鬼之间必须相邻等），就需要用分治法来构造解。

## 扩展版本：带编号的巨人与鬼

**问题升级**：
n 个巨人编号为 G1, G2, ..., Gn，n 个鬼编号为 g1, g2, ..., gn。

要求：
1. 巨人和鬼必须交替排列
2. 满足某些特定的相邻约束（例如：G1 不能和 g1 相邻）

这时就需要用**分治 + 回溯**来求解。

## 算法提示

### 基础版本（无编号）
直接输出交替序列即可：`G g G g ... G g`

### 扩展版本（有编号 + 约束）
使用分治法：
1. **递归基**：n=1 时，只有 G1 和 g1，直接输出
2. **分治步骤**：
   - 将 2n 个位置分为两半
   - 递归构造左半部分
   - 递归构造右半部分
   - 合并时确保交界处满足约束

## 时间复杂度

- **基础版本**：O(n)，直接输出
- **扩展版本（带约束）**：O(n!)，可能需要回溯搜索

## Example Illustration

n=3 的排列：
```
位置:  1   2   3   4   5   6
排列:  G   g   G   g   G   g
       └───┴───┴───┴───┴───┴─→ 首尾相连
```

验证：
- 位置1(G)的左右是位置6(g)和位置2(g) ✓
- 位置2(g)的左右是位置1(G)和位置3(G) ✓
- 以此类推...

## 相关问题

这个问题可以推广到：

2. **任务调度问题**：2n个任务分为两类，要求交替执行
3. **座位安排问题**：圆桌旁安排客人，满足某些相邻约束
