【题目概览】

- 一条单线地铁有 N 个按顺序编号的车站，列车往返双向行驶，相邻站间运行时间固定。女特工 Maria 要从 1 号站出发，在时刻 T 前抵达 N 号站与人会面。她在站台等待时风险最大，希望总等待时间最小，可随时换乘、并允许往返搭乘。求在给定时刻表下，使她能按时到达 N 号站的最小站台等待总时间；若无法准点抵达则输出 impossible。

【输入格式：逐句解释】

- 输入包含若干测试用例；每个用例 7 行：
  - 第 1 行：整数 N（2 ≤ N ≤ 50），车站数量。
  - 第 2 行：整数 T（0 ≤ T ≤ 200），会面时刻（限制到达时刻）。
  - 第 3 行：N−1 个整数 t1, t2, …, tN−1（1 ≤ ti ≤ 20），为相邻站的行车时间：t1 是 1→2，t2 是 2→3，以此类推。
  - 第 4 行：整数 M1（1 ≤ M1 ≤ 50），从 1 号站发车的列车数量。
  - 第 5 行：M1 个整数 d1 … dM1（0 ≤ di ≤ 250 且 di < di+1），这些列车从 1 号站发车的时刻。
  - 第 6 行：整数 M2（1 ≤ M2 ≤ 50），从 N 号站发车的列车数量。
  - 第 7 行：M2 个整数 e1 … eM2（0 ≤ ei ≤ 250 且 ei < ei+1），这些列车从 N 号站反向发车的时刻。
- “The last case is followed by a line containing a single zero.”：所有用例结束后有一行单独的 0 作为终止标记，不属于任何用例。
- 列车在站停靠时间可忽略，Maria 极快，可以在同一时刻完成换乘。

【输入格式（结构化摘要）】

字段顺序：

1. 第 1 行：N
   - 含义：车站数量
   - 类型：整数
   - 取值范围：2 ≤ N ≤ 50
   - 数据保证：给定
2. 第 2 行：T
   - 含义：会面时刻/要求到达的截止时间
   - 类型：整数
   - 取值范围：0 ≤ T ≤ 200
   - 数据保证：给定
3. 第 3 行：t1 … tN−1
   - 含义：相邻站行车时间
   - 类型：整数列表
   - 取值范围：1 ≤ ti ≤ 20
   - 数据保证：恰好 N−1 个，按站序给出
4. 第 4 行：M1
   - 含义：从 1 号站出发的列车数
   - 类型：整数
   - 取值范围：1 ≤ M1 ≤ 50
   - 数据保证：给定
5. 第 5 行：d1 … dM1
   - 含义：这些列车从 1 号站的发车时刻
   - 类型：整数列表递增
   - 取值范围：0 ≤ di ≤ 250，且严格递增
   - 数据保证：恰好 M1 个
6. 第 6 行：M2
   - 含义：从 N 号站出发的反向列车数
   - 类型：整数
   - 取值范围：1 ≤ M2 ≤ 50
   - 数据保证：给定
7. 第 7 行：e1 … eM2
   - 含义：这些列车从 N 号站的发车时刻（向 1 号方向）
   - 类型：整数列表递增
   - 取值范围：0 ≤ ei ≤ 250，且严格递增
   - 数据保证：恰好 M2 个

多组输入：

- 是否多组：是，连续多个用例。
- 每组格式：上述 7 行。
- 终止条件：遇到单独的 0 行。
- 终止行是否需要处理：否（仅结束标记）。

隐含条件 / 数据保证：

- 所有列车速度相同，行车时间按 ti 固定。
- 列车停站时间忽略，Maria 可在同一时刻完成换乘。
- 列车仅在两端给出的出发时刻发车，之后按固定行车时间依次到达中间站。
- Maria 可中途往返以减少等待，只要最终 T 时刻前到达 N 号站。

【输出格式】

- 对每个测试用例输出一行，格式：`Case Number k: X`，k 从 1 开始递增，X 为该用例的最小总等待时间；若无法按时到达，输出 `impossible` 替代整数。

6

- 用例 1：N=4, T=55；t=[5,10,15]；M1=4，正向发车时刻 0,5,10,20；M2=4，反向发车时刻 0,5,10,15。
- 用例 2：N=4, T=18；t=[1,2,3]；M1=5，正向发车 0,3,6,10,12；M2=6，反向发车 0,3,5,7,12,15。
- 用例 3：N=2, T=30；t=[20]；M1=1，正向发车 20；M2=7，反向发车 1,3,5,7,11,13,17。
- 末尾单独的 0 结束。

Sample Output：

```

Case Number 3: impossible
```

- 分别对应三个用例的最小等待时间或不可达判定。

【关键假设 / 陷阱】

- 终止行单独为“0”，不带其他数据；不要将其当作车站数。
- 列车时刻给的是两端发车时刻，需按行车时间推算到各中间站的到达/离开时刻。
- Maria 可在同一时刻换乘（停站时间忽略），但必须等待到列车实际到站/发车时刻才能上车。
- 等待时间仅计算站台等待，车上行驶时间不计入等待。
- 必须在时刻 T 到达 N 号站才能算成功，超过即视为不可达。

【解法提示（可选）】

- 可构造时间 DP：dp[time][station] 表示到该状态的最小等待；预先标记正向/反向列车在各站的到达是否可用，逆序时间填表；最终检查 dp[0][1] 是否能在 T 时刻到 N。
