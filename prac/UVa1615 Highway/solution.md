## 一、问题描述

### 1.1 题目背景

Bob 需要在一个人口稀少的地区设计高速公路，为了节省成本，他希望**最小化高速公路出口的数量**。

### 1.2 问题建模

- **高速公路**：x 轴上的线段，从 0 到 L
- **村庄**：平面上的 N 个点，坐标为 (x, y)
- **出口**：高速公路（x 轴）上的点
- **约束**：每个村庄到至少一个出口的距离 ≤ D
- **保证**：所有村庄到 x 轴的距离 ≤ D（即 y ≤ D）

### 1.3 输入格式

```
L               (高速公路长度)
D               (最大距离)
N               (村庄数量)
x1 y1           (村庄1坐标)
x2 y2           (村庄2坐标)
...
xN yN           (村庄N坐标)
```

**注意**：
- 多组测试数据，以 EOF 结束
- 使用 `while (cin >> L >> D >> N)` 读取
- L, D, N 是整数；x, y 推测也是整数

### 1.4 输出格式

对每组测试数据，输出一行：最少需要的出口数量。

## 三、核心思路：问题转化

### 3.1 从几何到区间

**关键洞察**：每个村庄对应 x 轴上的一个**可行区间**。

```
村庄 (x, y)
   ●
  ╱ ╲
 ╱   ╲   D
╱     ╲
━━━━━━━━━  ← x 轴
[  区间  ]
```

只要在这个区间内放置出口，该村庄就能被覆盖！

### 3.2 问题转化

**原问题**：
> 在 x 轴上选最少的点，使每个村庄到至少一个点的距离 ≤ D

**转化后**：
> 在数轴上有 N 个区间，选最少的点，使每个区间至少包含一个点

这是经典的**区间选点问题**（也叫**区间覆盖问题**）！

## 四、几何推导

### 4.1 推导过程

已知：
- 村庄位置：`(x, y)`
- 出口位置：`(exit_x, 0)`（在 x 轴上）
- 距离限制：`distance ≤ D`

根据**欧几里得距离公式**：

```
sqrt((exit_x - x)² + (0 - y)²) ≤ D

两边平方：
(exit_x - x)² + y² ≤ D²

移项：
(exit_x - x)² ≤ D² - y²

开方：
|exit_x - x| ≤ sqrt(D² - y²)

展开绝对值：
-sqrt(D² - y²) ≤ exit_x - x ≤ sqrt(D² - y²)

整理：
x - sqrt(D² - y²) ≤ exit_x ≤ x + sqrt(D² - y²)
```

### 4.2 区间公式

对于村庄 `(x, y)`，可行区间为：

```cpp
delta = sqrt(D² - y²)
left = x - delta
right = x + delta
```

**注意**：
1. 题目保证 `y ≤ D`，所以 `D² - y²` 非负
2. 区间需要裁剪到 `[0, L]` 范围内

### 4.3 样例计算

**村庄1：(2, 4)**
```
delta = sqrt(50² - 4²) = sqrt(2484) ≈ 49.84
left = 2 - 49.84 = -47.84 → 裁剪为 0
right = 2 + 49.84 = 51.84
区间：[0, 51.84]
```

**村庄2：(50, 10)**
```
delta = sqrt(50² - 10²) = sqrt(2400) ≈ 48.99
left = 50 - 48.99 = 1.01
right = 50 + 48.99 = 98.99
区间：[1.01, 98.99]
```

**村庄3：(70, 30)**
```
delta = sqrt(50² - 30²) = sqrt(1600) = 40
left = 70 - 40 = 30
right = 70 + 40 = 110 → 裁剪为 100
区间：[30, 100]
```

**转化后的问题**：
```
区间1: [0, 51.84]
区间2: [1.01, 98.99]
区间3: [30, 100]

问：最少选几个点，让每个区间都包含至少一个点？
```

## 五、贪心策略详解

### 5.1 策略概述

区间选点问题的贪心策略：
1. **按右端点排序**（右端点小的在前；右端点相同则左端点小的在前）
2. **每次选择当前区间的右端点**
3. **跳过所有被覆盖的区间**

### 5.2 为什么按右端点排序？

**原因1：处理区间包含关系**

```
区间A: [──────]
区间B: [────────────]  (包含区间A)

按右端点排序后，区间A在前
如果为A选了一个点，B自动被覆盖！
```

**原因2：保证贪心的正确性**

排序后，每次选择右端点能让点"尽可能靠右"，从而覆盖更多后续区间。

### 5.3 为什么选择右端点？

**图示说明**：

```
情况1：选择右端点（最优）
区间1: [──────────●]     ← 黑点：右端点
区间2:       [────────]  ← 被覆盖 ✓
区间3:            [──]   ← 被覆盖 ✓
总共：1 个点

情况2：选择中间（次优）
区间1: [────●─────]      ← 红点：中间
区间2:       [────────]  ← 不被覆盖 ✗
区间3:            [──]   ← 不被覆盖 ✗
总共：需要更多点
```

**结论**：选择右端点能覆盖最多的后续区间！

### 5.4 贪心算法流程

```
1. 按右端点对所有区间排序
2. 初始化：count = 0, last_point = -∞
3. 对每个区间 [left, right]：
   - 如果 last_point < left：
     * 当前区间未被覆盖
     * count++
     * last_point = right（选择右端点）
   - 否则：
     * 当前区间已被覆盖，跳过
4. 返回 count
```

### 5.5 样例贪心过程

**排序后的区间**（按右端点）：
```
区间1: [0,      51.84]
区间2: [1.01,   98.99]
区间3: [30,     100  ]
```

**贪心选点**：
```
初始：count = 0, last_point = -∞

处理区间1 [0, 51.84]:
  -∞ < 0 ？ 是
  → 需要新点
  → count = 1
  → last_point = 51.84

处理区间2 [1.01, 98.99]:
  51.84 < 1.01 ？ 否（51.84 在区间内）
  → 已被覆盖，跳过

处理区间3 [30, 100]:
  51.84 < 30 ？ 否（51.84 在区间内）
  → 已被覆盖，跳过

结果：count = 1
```

**答案：1 个出口（位置约在 x = 51.84）**

## 六、算法步骤

### 步骤1：计算区间

```cpp
for (int i = 0; i < N; i++) {
    cin >> x >> y;

    // 计算可行区间
    double delta = sqrt((double)D*D - (double)y*y);
    double left = x - delta;
    double right = x + delta;

    // 裁剪到 [0, L]
    left = max(0.0, left);
    right = min((double)L, right);

    intervals.push_back({left, right});
}
```

### 步骤2：排序

```cpp
sort(intervals.begin(), intervals.end(),
     [](auto& a, auto& b) {
         if (a.second != b.second)
             return a.second < b.second;  // 右端点小的在前
         return a.first < b.first;        // 右端点相同，左端点小的在前
     });
```

### 步骤3：贪心选点

```cpp
int count = 0;
double last = -1e9;  // 初始化为不可能的值

for (auto [left, right] : intervals) {
    if (last < left) {  // 当前区间未被覆盖
        count++;
        last = right;   // 选择右端点
    }
}

cout << count << "\n";
```

## 七、代码实现

### 7.1 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int L, D, N;

    // 多组测试数据，以 EOF 结束
    while (cin >> L >> D >> N) {
        vector<pair<double, double>> intervals;

        // 步骤1：读取村庄并计算区间
        for (int i = 0; i < N; i++) {
            long long x, y;
            cin >> x >> y;

            // 计算可行区间
            double delta = sqrt((double)D * D - (double)y * y);
            double left = x - delta;
            double right = x + delta;

            // 裁剪到 [0, L]
            left = max(0.0, left);
            right = min((double)L, right);

            // 存储区间
            intervals.push_back({left, right});
        }

        // 步骤2：按右端点排序
        sort(intervals.begin(), intervals.end(),
             [](const auto& a, const auto& b) {
                 if (a.second != b.second)
                     return a.second < b.second;
                 return a.first < b.first;
             });

        // 步骤3：贪心选点
        int count = 0;
        double last_point = -1e9;

        for (auto [left, right] : intervals) {
            if (last_point < left) {
                // 当前区间未被覆盖，需要新点
                count++;
                last_point = right;  // 选择右端点
            }
            // 否则当前区间已被覆盖，跳过
        }

        cout << count << "\n";
    }

    return 0;
}
```

### 7.2 代码说明

**数据类型选择**：
- `L, D, N`：int（题目说明是整数）
- `x, y`：long long（防止平方时溢出）
- `left, right`：double（sqrt 返回浮点数）
- `intervals`：vector<pair<double, double>>

**关键点**：
1. `(double)D * D - (double)y * y`：先转 double，避免溢出
2. `last_point = -1e9`：初始化为负无穷
3. 排序使用 lambda 表达式，清晰直观

## 八、复杂度分析

### 8.1 时间复杂度

- **计算区间**：O(N)
  - 每个村庄计算一次，O(1) per village

- **排序**：O(N log N)
  - 对 N 个区间排序

- **贪心选点**：O(N)
  - 遍历一次区间

**总时间复杂度**：**O(N log N)**

### 8.2 空间复杂度

- **存储区间**：O(N)
- **其他变量**：O(1)

**总空间复杂度**：**O(N)**

### 8.3 性能分析

对于 N ≤ 10^5：
- O(N log N) ≈ 10^5 × 17 ≈ 1.7 × 10^6 次操作
- 完全可以接受（< 1 秒）

## 九、易错点总结

### 9.1 数据类型

❌ **错误**：
```cpp
int D, x, y;
double delta = sqrt(D*D - y*y);  // 可能溢出！
```

✅ **正确**：
```cpp
long long x, y;
int D;
double delta = sqrt((double)D*D - (double)y*y);
```

**原因**：`D*D` 和 `y*y` 可能超过 int 范围（2^31 - 1 ≈ 2×10^9）。

### 9.2 区间裁剪

❌ **错误**：
```cpp
left = max(1.0, left);   // 高速公路从 0 开始，不是 1！
right = min(INF*1.0, right);  // 应该用实际长度 L
```

✅ **正确**：
```cpp
left = max(0.0, left);
right = min((double)L, right);
```

### 9.3 排序条件

❌ **错误**（只按右端点）：
```cpp
sort(intervals.begin(), intervals.end(),
     [](auto& a, auto& b) {
         return a.second < b.second;  // 不完整！
     });
```

✅ **正确**（右端点相同时比较左端点）：
```cpp
sort(intervals.begin(), intervals.end(),
     [](auto& a, auto& b) {
         if (a.second != b.second)
             return a.second < b.second;
         return a.first < b.first;  // 稳定排序
     });
```

### 9.4 判断条件

❌ **错误**：
```cpp
if (last < left || last > right)  // 复杂且有冗余
```

✅ **正确**：
```cpp
if (last < left)  // 简洁且充分
```

**原因**：区间已按右端点排序，`last > right` 不可能发生。

### 9.5 边界情况

**情况1**：N = 0
- 理论上输出 0
- 题目可能保证 N ≥ 1

**情况2**：村庄在 x 轴上（y = 0）
- `delta = sqrt(D² - 0) = D`
- 区间变成 `[x-D, x+D]`
- 正常处理即可

**情况3**：村庄距离 x 轴恰好为 D（y = D）
- `delta = sqrt(D² - D²) = 0`
- 区间变成一个点 `[x, x]`
- 必须在 x 位置放出口

**情况4**：所有区间完全重叠
- 只需要 1 个出口
- 贪心算法自动处理

## 十、贪心正确性证明

### 10.1 定理

**定理**：按右端点排序，每次选择区间的右端点，得到的解是最优解。

### 10.2 证明（交换论证法）

**设定**：
- 贪心算法选择的点：`g₁, g₂, ..., gₖ`
- 最优解选择的点：`o₁, o₂, ..., oₘ`
- 区间已按右端点排序

**目标**：证明 `k = m`（贪心解 = 最优解）

**证明**：

1. **归纳假设**：对于前 i 个点，有 `gᵢ ≥ oᵢ`
   - 即：贪心选的点不比最优解的点靠左

2. **基础情况**（i=1）：
   - 贪心选择第一个区间的右端点：`g₁ = right[1]`
   - 最优解也必须覆盖第一个区间：`o₁ ∈ [left[1], right[1]]`
   - 因此 `g₁ ≥ o₁` ✓

3. **归纳步骤**：
   - 假设 `gᵢ ≥ oᵢ` 成立
   - 贪心选择第 i+1 个点是因为区间 j 无法被 `gᵢ` 覆盖
   - 即 `gᵢ < left[j]`
   - 因为 `gᵢ ≥ oᵢ`，所以 `oᵢ < left[j]`
   - 因此最优解也必须选择新点来覆盖区间 j
   - 贪心选择 `gᵢ₊₁ = right[j]`（尽可能靠右）
   - 所以 `gᵢ₊₁ ≥ oᵢ₊₁` ✓

4. **结论**：
   - 归纳得出：贪心解的每个点都不比最优解靠左
   - 因此贪心解选的点数 ≤ 最优解选的点数
   - 即 `k ≤ m`
   - 但最优解已经是最少的，所以 `k = m`

**证毕** ∎

### 10.3 直观理解

**核心思想**：
- 每次选择"尽可能靠右"的点
- 能覆盖最多的后续区间
- 因此总共需要的点最少
