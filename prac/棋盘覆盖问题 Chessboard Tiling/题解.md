# 棋盘覆盖问题 - 分治法详解

## 核心思想

**分治法三步走**：
1. **分解**：将 2^k × 2^k 棋盘分为 4 个 2^(k-1) × 2^(k-1) 子棋盘
2. **处理**：用一个 L 型骨牌覆盖 3 个子棋盘的角落（不包括有特殊方格的子棋盘）
3. **递归**：每个子棋盘都有一个"特殊方格"，递归求解

## 关键问题拆解

### 问题1：如何表示棋盘？

```cpp
int board[MAX_SIZE][MAX_SIZE];  // 存储每个格子属于哪个骨牌
int tile = 1;                    // 全局骨牌编号，每用一个L型骨牌就+1
```

- `board[i][j] = 0` 表示特殊方格
- `board[i][j] = k` 表示该格子被第 k 号骨牌覆盖

### 问题2：如何分解棋盘？

对于一个起点为 (tr, tc)、大小为 size×size 的棋盘：

```
左上子棋盘: (tr,         tc        ) 大小 size/2 × size/2
右上子棋盘: (tr,         tc+size/2 ) 大小 size/2 × size/2
左下子棋盘: (tr+size/2,  tc        ) 大小 size/2 × size/2
右下子棋盘: (tr+size/2,  tc+size/2 ) 大小 size/2 × size/2
```

```
(tr, tc) ───────────────┐
    │     size/2        │
    │  ┌────────┬───────┤
    │  │   左上  │  右上 │
size │  │        │       │
    │  ├────────┼───────┤ ← tr+size/2
    │  │   左下  │  右下 │
    │  │        │       │
    └──┴────────┴───────┘
       │        ↑
       │     tc+size/2
       tc
```

### 问题3：如何找到特殊方格在哪个子棋盘？

```cpp
// 特殊方格坐标 (dr, dc)
// 中心点：(tr + size/2, tc + size/2)

if (dr < tr + size/2 && dc < tc + size/2) {
    // 在左上子棋盘
} else if (dr < tr + size/2 && dc >= tc + size/2) {
    // 在右上子棋盘
} else if (dr >= tr + size/2 && dc < tc + size/2) {
    // 在左下子棋盘
} else {
    // 在右下子棋盘
}
```

### 问题4：如何放置L型骨牌？

**关键思想**：在中心交汇处放一个 L 型骨牌，覆盖**不包含特殊方格的 3 个子棋盘**各自的角落。

```
假设特殊方格在左上子棋盘：

┌─────────┬─────────┐
│  左上   │   右上  │
│        ●│■        │  ● = 特殊方格
├─────────┼─────────┤  ■ = 本次放置的L型骨牌
│  左下   │   右下  │     (覆盖右上、左下、右下的角落)
│■        │■        │
└─────────┴─────────┘
```

放置位置：
- **右上子棋盘的左下角**：`(tr + size/2 - 1, tc + size/2)`
- **左下子棋盘的右上角**：`(tr + size/2, tc + size/2 - 1)`
- **右下子棋盘的左上角**：`(tr + size/2, tc + size/2)`

这 3 个格子恰好组成一个 L 型！

### 问题5：递归时如何传递"特殊方格"？

放置完 L 型骨牌后，4 个子棋盘各自都有一个"特殊方格"：

```cpp
// 假设原特殊方格在左上子棋盘
// 那么递归4次：

// 1. 左上子棋盘：特殊方格是原来的 (dr, dc)
chessBoard(tr, tc, dr, dc, size/2);

// 2. 右上子棋盘：特殊方格是刚放的骨牌，即 (tr+size/2-1, tc+size/2)
chessBoard(tr, tc+size/2, tr+size/2-1, tc+size/2, size/2);

// 3. 左下子棋盘：特殊方格是刚放的骨牌，即 (tr+size/2, tc+size/2-1)
chessBoard(tr+size/2, tc, tr+size/2, tc+size/2-1, size/2);

// 4. 右下子棋盘：特殊方格是刚放的骨牌，即 (tr+size/2, tc+size/2)
chessBoard(tr+size/2, tc+size/2, tr+size/2, tc+size/2, size/2);
```

## 完整算法流程

```
函数 chessBoard(tr, tc, dr, dc, size):
    参数说明：
    - (tr, tc): 当前棋盘的左上角坐标
    - (dr, dc): 特殊方格的坐标
    - size: 当前棋盘的边长

    1. 递归基：if size == 2
       → 2×2棋盘，直接放一个L型骨牌覆盖非特殊方格的3格
       → 返回

    2. 分解：计算4个子棋盘的位置
       half = size / 2
       t = 当前骨牌编号（tile++）

    3. 判断特殊方格在哪个子棋盘，并放置L型骨牌：

       if 特殊方格在左上:
           board[tr+half-1][tc+half]   = t  // 右上的左下角
           board[tr+half][tc+half-1]   = t  // 左下的右上角
           board[tr+half][tc+half]     = t  // 右下的左上角

       if 特殊方格在右上:
           board[tr+half-1][tc+half-1] = t  // 左上的右下角
           board[tr+half][tc+half-1]   = t  // 左下的右上角
           board[tr+half][tc+half]     = t  // 右下的左上角

       if 特殊方格在左下:
           board[tr+half-1][tc+half-1] = t  // 左上的右下角
           board[tr+half-1][tc+half]   = t  // 右上的左下角
           board[tr+half][tc+half]     = t  // 右下的左上角

       if 特殊方格在右下:
           board[tr+half-1][tc+half-1] = t  // 左上的右下角
           board[tr+half-1][tc+half]   = t  // 右上的左下角
           board[tr+half][tc+half-1]   = t  // 左下的右上角

    4. 递归4个子棋盘（每个子棋盘的特殊方格已确定）
       chessBoard(左上子棋盘...)
       chessBoard(右上子棋盘...)
       chessBoard(左下子棋盘...)
       chessBoard(右下子棋盘...)
```

## 代码组织结构

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const int MAX_SIZE = 100;
int board[MAX_SIZE][MAX_SIZE];
int tile = 1;  // 全局骨牌编号

// 核心递归函数
void chessBoard(int tr, int tc, int dr, int dc, int size) {
    // 1. 递归基
    if (size == 2) { ... }

    // 2. 分解 + 放置L型骨牌
    int half = size / 2;
    int t = tile++;

    // 3. 判断特殊方格位置 + 放置骨牌
    if (特殊方格在左上) {
        // 放置骨牌到右上、左下、右下的角落
        // 递归4次
    } else if (特殊方格在右上) {
        // ...
    } else if (特殊方格在左下) {
        // ...
    } else {
        // ...
    }
}

int main() {
    int k, sr, sc;
    cin >> k >> sr >> sc;

    int size = pow(2, k);
    board[sr][sc] = 0;  // 标记特殊方格

    chessBoard(0, 0, sr, sc, size);

    // 输出结果
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            cout << board[i][j];
            if (j < size - 1) cout << " ";
        }
        cout << "\n";
    }

    return 0;
}
```

## 关键技巧总结

1. **全局骨牌编号**：用 `tile` 变量递增，每次放置L型骨牌时 `tile++`

2. **坐标映射**：
   - 棋盘左上角 `(tr, tc)` 确定子棋盘位置
   - 中心点 `(tr + half, tc + half)` 用于分界

3. **L型骨牌的 3 个格子**：
   - 总是在中心交汇的 3 个角落
   - 跳过包含特殊方格的子棋盘

4. **递归传参**：
   - 每个子棋盘的起点、特殊方格位置、边长
   - 特殊方格要么是原有的，要么是刚放置的骨牌位置

5. **递归基**：
   - `size == 2` 时直接放一个骨牌
   - 遍历 2×2 区域，跳过特殊方格，其余3格标记为同一编号

## 复杂度分析

- **时间复杂度**：T(n) = 4T(n/2) + O(1) = O(n²)，其中 n = 2^k
  - 每次分解为4个子问题
  - 每层常数时间放置一个骨牌

- **空间复杂度**：O(n²) 存储棋盘 + O(log n) 递归栈深度

```
初始:

. . | . .

```
