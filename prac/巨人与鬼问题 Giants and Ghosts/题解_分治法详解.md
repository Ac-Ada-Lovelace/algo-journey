# 巨人与鬼问题 - 分治法详解

## 分治法核心思想

### 基本策略

将平面上的 n 个巨人和 n 个鬼分为两组，使得：
- 左边有 k 个巨人和 k 个鬼
- 右边有 n-k 个巨人和 n-k 个鬼
- **关键**：左边的巨人只配对左边的鬼，右边的巨人只配对右边的鬼

这样就保证了左边的连线不会与右边的连线相交！

### 分治三步骤

1. **分解**：找到一条分割线（通常是竖直线），将所有点分为两部分
2. **递归**：分别解决左右两个子问题
3. **合并**：由于分割保证了左右不会交叉，直接合并结果即可

## 详细算法流程

### 方法1：中位数分割法

**核心思想**：用一条竖直线分割，使得左右两边巨人和鬼的数量相等。

#### 步骤详解

```
输入：n 个巨人 G[]，n 个鬼 g[]

1. 递归基：
   if n == 1:
       配对唯一的巨人和唯一的鬼
       return

2. 计算所有点（巨人+鬼）的 x 坐标中位数 mx

3. 分组：
   - 统计 x < mx 的巨人数量 left_G
   - 统计 x < mx 的鬼数量 left_g

4. 平衡调整：
   - 如果 left_G == left_g == k：完美！
   - 如果 left_G > left_g：
     * 将一些 x >= mx 的鬼移到左边
     * 或将一些 x < mx 的巨人移到右边
   - 如果 left_G < left_g：反之

   目标：确保左边恰好有 k 个巨人和 k 个鬼（k = n/2）

5. 递归求解：
   solve(左边的巨人, 左边的鬼)
   solve(右边的巨人, 右边的鬼)
```

#### 关键问题：如何平衡？

**简化策略**：直接按 x 坐标排序后强制分组

```cpp
// 将巨人和鬼都按 x 坐标排序
sort(giants, giants + n, cmp_x);
sort(ghosts, ghosts + n, cmp_x);

// 强制分为两半
left_giants = giants[0 ... n/2-1]
right_giants = giants[n/2 ... n-1]
left_ghosts = ghosts[0 ... n/2-1]
right_ghosts = ghosts[n/2 ... n-1]

// 递归
solve(left_giants, left_ghosts);
solve(right_giants, right_ghosts);
```

**为什么这样是对的？**

因为排序后：
- 左边所有巨人的 x 坐标 ≤ 右边所有巨人的 x 坐标
- 左边所有鬼的 x 坐标 ≤ 右边所有鬼的 x 坐标
- 因此左边的任意连线不可能与右边的任意连线相交

### 方法2：基于凸包的分治法

**更通用的策略**，适用于任意点分布。

#### 核心思想

1. 找到所有点的**凸包**
2. 从凸包上选择一条边作为分割线
3. 将点集分为分割线两侧
4. 递归处理

#### 详细步骤

```
1. 计算所有 2n 个点的凸包

2. 在凸包上找一条边 e，使得：
   - e 两侧的巨人数量相等（或尽量接近）
   - e 两侧的鬼数量相等（或尽量接近）

3. 用 e 将平面分为两部分

4. 递归处理两侧的点
```

**优点**：
- 更灵活，适应任意点分布
- 可以处理点密集或特殊分布的情况

**缺点**：
- 实现复杂
- 时间复杂度较高

## 代码实现

### 实现1：排序分治法（推荐）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    double x, y;
    int id;
};

bool cmp_x(const Point& a, const Point& b) {
    if (abs(a.x - b.x) > 1e-9) return a.x < b.x;
    return a.y < b.y;
}

vector<int> match;  // match[i] = 第i个巨人配对的鬼编号

// giants: 巨人索引列表, ghosts: 鬼索引列表
// all_giants, all_ghosts: 存储所有点的数组
void solve(vector<int> giants, vector<int> ghosts,
           vector<Point>& all_giants, vector<Point>& all_ghosts) {
    int n = giants.size();

    // 递归基
    if (n == 0) return;
    if (n == 1) {
        match[giants[0]] = ghosts[0];
        return;
    }

    // 按 x 坐标排序当前子问题的巨人和鬼
    sort(giants.begin(), giants.end(), [&](int a, int b) {
        return cmp_x(all_giants[a], all_giants[b]);
    });
    sort(ghosts.begin(), ghosts.end(), [&](int a, int b) {
        return cmp_x(all_ghosts[a], all_ghosts[b]);
    });

    // 分为两半
    int half = n / 2;

    vector<int> left_giants(giants.begin(), giants.begin() + half);
    vector<int> right_giants(giants.begin() + half, giants.end());
    vector<int> left_ghosts(ghosts.begin(), ghosts.begin() + half);
    vector<int> right_ghosts(ghosts.begin() + half, ghosts.end());

    // 递归处理
    solve(left_giants, left_ghosts, all_giants, all_ghosts);
    solve(right_giants, right_ghosts, all_giants, all_ghosts);
}

int main() {
    int n;
    cin >> n;

    vector<Point> giants(n), ghosts(n);
    match.resize(n);

    // 读入数据
    for (int i = 0; i < n; i++) {
        cin >> giants[i].x >> giants[i].y;
        giants[i].id = i;
    }
    for (int i = 0; i < n; i++) {
        cin >> ghosts[i].x >> ghosts[i].y;
        ghosts[i].id = i;
    }

    // 初始化索引列表
    vector<int> g_ids(n), d_ids(n);
    for (int i = 0; i < n; i++) {
        g_ids[i] = i;
        d_ids[i] = i;
    }

    // 分治求解
    solve(g_ids, d_ids, giants, ghosts);

    // 输出结果（编号从1开始）
    for (int i = 0; i < n; i++) {
        cout << match[i] + 1 << "\n";
    }

    return 0;
}
```

### 时间复杂度分析

**递推式**：
```
T(n) = 2T(n/2) + O(n log n)
```

- 每次分治需要排序：O(n log n)
- 分为两个 n/2 规模的子问题：2T(n/2)

**主定理分析**：
- a = 2, b = 2, f(n) = n log n
- n^(log_b a) = n^(log_2 2) = n
- f(n) = n log n > n，满足主定理 Case 3
- 因此 T(n) = Θ(n log² n)

**优化到 O(n log n)**：
如果我们只在最开始排序一次，然后在递归中只传递排序好的索引：

```cpp
// 预先排序一次
sort(giants.begin(), giants.end(), cmp_x);
sort(ghosts.begin(), ghosts.end(), cmp_x);

// 递归时不再排序，直接分割
void solve_optimized(int l1, int r1, int l2, int r2) {
    // giants[l1...r1] 对应 ghosts[l2...r2]
    if (l1 == r1) {
        match[giants[l1].id] = ghosts[l2].id;
        return;
    }

    int mid1 = (l1 + r1) / 2;
    int mid2 = (l2 + r2) / 2;

    solve_optimized(l1, mid1, l2, mid2);
    solve_optimized(mid1 + 1, r1, mid2 + 1, r2);
}
```

这样时间复杂度降为：
```
T(n) = 2T(n/2) + O(1) = O(n)
```

总复杂度：O(n log n)（排序）+ O(n)（递归）= **O(n log n)**

## 可视化示例

### 例子：n=4

```
巨人：G1(0,0), G2(1,3), G3(4,1), G4(5,4)
鬼：  g1(0,2), g2(2,1), g3(4,3), g4(6,2)
```

#### 第一层递归（分割）

```
按 x 坐标排序：
巨人：G1(0,0) < G2(1,3) < G3(4,1) < G4(5,4)
鬼：  g1(0,2) < g2(2,1) < g3(4,3) < g4(6,2)

分割线 x = 2.5（中点）

左边：G1, G2  和  g1, g2
右边：G3, G4  和  g3, g4
```

#### 第二层递归（左边）

```
左边子问题：
巨人：G1(0,0), G2(1,3)
鬼：  g1(0,2), g2(2,1)

配对：
G1 → g1
G2 → g2
```

#### 第二层递归（右边）

```
右边子问题：
巨人：G3(4,1), G4(5,4)
鬼：  g3(4,3), g4(6,2)

配对：
G3 → g3
G4 → g4
```

#### 最终结果

```
      g1(0,2)
       │
       │
   G1(0,0)    g2(2,1)
               │
          G2(1,3)
                           g3(4,3)
                            │
                       G3(4,1)    g4(6,2)
                                   │
                              G4(5,4)

配对：G1→g1, G2→g2, G3→g3, G4→g4
可以验证四条线段互不相交！
```

## 分治法的优势

### 与排序法对比

| 特性 | 排序法 | 分治法 |
|------|--------|--------|
| 时间复杂度 | O(n log n) | O(n log n) 或 O(n log² n) |
| 空间复杂度 | O(n) | O(n log n)（递归栈） |
| 实现难度 | ⭐ 简单 | ⭐⭐ 中等 |
| 通用性 | 仅适用于无约束 | 可扩展到有约束情况 |
| 算法思想 | 贪心 + 排序 | 分治 + 递归 |

### 分治法的扩展性

分治法可以处理更复杂的情况：

1. **带禁止约束**：某些巨人不能配某些鬼
   - 在分治时检查约束
   - 调整分组策略

2. **带距离约束**：配对距离不能超过某个阈值
   - 在分治时剪枝
   - 结合动态规划

3. **最优化目标**：最小化总距离
   - 每个子问题求最优解
   - 合并时选择最优分割方式

## 关键引理

### 引理：分治法的正确性

**定理**：如果将 n 个巨人和 n 个鬼按 x 坐标排序后分为两组：
- 左组：前 k 个巨人和前 k 个鬼
- 右组：后 n-k 个巨人和后 n-k 个鬼

则左组的任意匹配不会与右组的任意匹配相交。

**证明**：
设左组的任意连线为 L，右组的任意连线为 R。

- L 的两个端点 x 坐标都 ≤ 排序后第 k 个点的 x 坐标
- R 的两个端点 x 坐标都 ≥ 排序后第 k+1 个点的 x 坐标
- 因此 L 和 R 的 x 范围不重叠（或至多在边界相切）
- 所以 L 和 R 不可能相交

证毕。■

### 引理：递归深度

分治树的高度为 **log n**，因为每次将问题规模减半。

## 总结

**分治法精髓**：
1. **分组**：按 x 坐标排序后平分
2. **递归**：独立求解左右子问题
3. **合并**：直接合并（无需额外操作）

**关键洞察**：
- 排序保证了子问题的独立性
- 左边的配对和右边的配对不会相互干扰
- 这是分治法能够工作的根本原因

**复杂度**：
- 朴素分治：O(n log² n)
- 优化分治：O(n log n)

分治法虽然和排序法结果一样，但它展示了更深刻的算法思想，是学习分治策略的极佳例题！
