## 【题目概览】
有一排连续房屋，每间房屋有一定现金。小偷不会偷相邻房屋。小偷的窃取能力定义为他偷过的房屋中单间金额的最大值。给定数组 `nums` 表示每间房屋现金，以及整数 `k` 表示至少要偷的房屋数（保证能偷到至少 `k` 间）。返回在所有“至少偷 `k` 间房屋”的方案中，小偷的最小窃取能力。

## 【函数输入：逐段解释】
1. 有若干连续房屋，小偷拒绝偷相邻房屋。  
2. 窃取能力是他所偷房屋中“单间金额最大值”。  
3. 输入数组 `nums`，第 `i` 间房屋有 `nums[i]` 美元。  
4. 输入整数 `k`，表示最少要偷的房屋数，且总能偷到至少 `k` 间。  
5. 输出：在所有“至少偷 `k` 间”的方案中，最小的窃取能力。  

## 【输入格式（结构化摘要）——字段清单形式】
字段顺序：
1. 参数 `nums`
   - 含义：每间房屋的现金金额
   - 类型：整数数组
   - 取值范围：`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`
   - 数据保证：题面保证总能偷到至少 `k` 间房屋

2. 参数 `k`
   - 含义：至少要偷的房屋数量
   - 类型：整数
   - 取值范围：`1 <= k <= (nums.length + 1) / 2`
   - 数据保证：题面保证总能偷到至少 `k` 间房屋

多组输入：
- 是否多组：否（函数调用一次处理一组参数）
- 每组格式：`nums`, `k`
- 终止条件：不适用
- 终止行是否需要处理：不适用

隐含条件 / 数据保证：
- 题面明确说明小偷不会偷相邻房屋
- 题面明确说明总能偷到至少 `k` 间房屋

## 【返回值 / 输出格式】
返回一个整数，表示在所有“至少偷 `k` 间”的方案中，最小的窃取能力。

## 【样例（完整引用 + 参数解释）】
示例 1：
```
Input: nums = [2,3,5,9], k = 2
Output: 5
Explanation: 
There are three ways to rob at least 2 houses:
- Rob the houses at indices 0 and 2. Capability is max(nums[0], nums[2]) = 5.
- Rob the houses at indices 0 and 3. Capability is max(nums[0], nums[3]) = 9.
- Rob the houses at indices 1 and 3. Capability is max(nums[1], nums[3]) = 9.
Therefore, we return min(5, 9, 9) = 5.
```
参数解释：
- `nums = [2,3,5,9]`
- `k = 2`
输出对应本组输入。

示例 2：
```
Input: nums = [2,7,9,3,1], k = 2
Output: 2
Explanation: There are 7 ways to rob the houses. The way which leads to minimum capability is to rob the house at index 0 and 4. Return max(nums[0], nums[4]) = 2.
```
参数解释：
- `nums = [2,7,9,3,1]`
- `k = 2`
输出对应本组输入。

## 【关键假设 / 陷阱】
- 不可偷相邻房屋（题面明确）
- 需要偷“至少”`k` 间，而不是恰好 `k` 间（题面明确）
- 窃取能力是被偷房屋中单间金额的最大值（题面明确定义）
- 题面保证总能偷到至少 `k` 间房屋
- 约束：`1 <= nums.length <= 10^5`，`1 <= nums[i] <= 10^9`，`1 <= k <= (nums.length + 1)/2`
