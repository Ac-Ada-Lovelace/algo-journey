【题目概览】
给定一个按非递减顺序排列的整数数组 nums，原地删除重复元素，使每个唯一元素只出现一次，且相对顺序保持不变。返回去重后唯一元素的数量 k。nums 的前 k 个元素应为排序后的唯一元素，其余位置内容可忽略。

【函数输入：逐段解释】
1. 给定一个按非递减顺序排列的整数数组 nums，需要原地去重，使每个唯一元素只出现一次，并保持相对顺序不变。
2. 设 nums 中唯一元素的数量为 k，去重后返回 k。
3. 去重后，nums 的前 k 个元素应包含按排序顺序的唯一数字，下标 k - 1 之后的元素可以忽略。
4. 评测使用自定义判题代码：调用 removeDuplicates(nums)，比较返回值 k 与 expectedNums 长度，并检查 nums[0..k-1] 是否与 expectedNums 一致。
5. 若所有断言通过，则判题通过。

【输入格式（结构化摘要）——字段清单形式】
字段顺序：
1. 参数 nums
   - 含义：待去重的整数数组
   - 类型：integer[]
   - 取值范围：-100 <= nums[i] <= 100
   - 数据保证：nums 已按非递减顺序排列
   - 长度约束：1 <= nums.length <= 3 * 10^4

多组输入：
- 是否多组：否（函数式调用）
- 终止条件：不适用

隐含条件 / 数据保证：
- 相对顺序保持不变
- 只要求前 k 个元素正确，其余元素可忽略

【返回值 / 输出格式】
返回一个整数 k，表示去重后唯一元素的数量。评测只检查 nums 的前 k 个元素是否与期望一致；下标 k - 1 之后的内容不参与评测。

【样例（完整引用 + 参数解释）】
示例 1（完整引用）：
```
Input: nums = [1,1,2]
Output: 2, nums = [1,2,_]
Explanation: Your function should return k = 2, with the first two elements of nums being 1 and 2 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).
```
参数解释：nums = [1,1,2]。

示例 2（完整引用）：
```
Input: nums = [0,0,1,1,1,2,2,3,3,4]
Output: 5, nums = [0,1,2,3,4,_,_,_,_,_]
Explanation: Your function should return k = 5, with the first five elements of nums being 0, 1, 2, 3, and 4 respectively.
It does not matter what you leave beyond the returned k (hence they are underscores).
```
参数解释：nums = [0,0,1,1,1,2,2,3,3,4]。

【关键假设 / 陷阱】
- nums 已按非递减顺序排列
- 必须原地修改数组，仅返回 k
- 评测只关注 nums 前 k 个元素，其余元素可忽略
