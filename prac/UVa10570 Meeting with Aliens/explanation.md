【题目概览】

- 有 N 个外星人围坐圆桌，编号 1..N。正确顺序要求：第 i 个坐在 (i−1) 和 (i+1) 之间（1 的左右是 2 和 N）。
- 当前给出一圈上的 N 个编号顺序（圆环，无固定起点或方向）。一次操作可交换任意两名外星人位置。求恢复到正确环形顺序所需的最少交换次数。

【输入格式：逐句解释】

- 输入以一个正整数 N 开始（3 ≤ N ≤ 500），表示外星人数量。
- 接下来若干行给出 N 个 1..N 的不同整数，表示当前环形座次顺序（从某个位置开始按顺/逆时针列出）。
- 多组数据，N=0 结束，不处理该组。
- 数据集不超过 100 组。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：N
   - 含义：外星人数。
   - 类型：整数。
   - 取值范围：3 ≤ N ≤ 500；N=0 表示结束。
   - 数据保证：正整数；0 仅作终止标记，不构成数据集。

2. 若干行合计 N 个整数：a1..aN
   - 含义：当前圆桌顺序，从某位置起按一个方向依次给出的编号。
   - 类型：整数。
   - 范围：1..N。
   - 数据保证：N 个整数两两不同，构成 1..N 的一个排列。

多组输入：

- 是否多组：是。
- 每组格式：先 N，再排列。
- 终止条件：读到 N=0。
- 终止行是否处理：否。

隐含条件 / 数据保证：

- 正确顺序是 1,2,3,...,N 按环连接；允许任意起点和方向视为同一正确顺序的旋转/反转。
- 输入排列完整且无重复（题面明示“distinct”）。

【输出格式】

- 对每组数据，输出一个整数，表示将当前座次调整为正确顺序所需的最少交换次数。
- 每组一行，仅该整数，无前缀/后缀。

【样例输入输出（完整引用 + 输入部分解释）】
样例输入：

```
4
1 2 3 4
4
4 3 2 1
4
2 3 1 4
0
```

样例输出：

```
0
0
1
```

样例解释：

- 例1：排列 1 2 3 4 本身就是合法环序（旋转/方向均合法），无需交换。
- 例2：4 3 2 1 可视作合法顺序的反向旋转，也无需交换。
- 例3：2 3 1 4 经过 1 次交换可转为合法顺序（如交换 1 和 2）。

【关键假设 / 陷阱】

- 正确顺序允许旋转和方向翻转，需同时考虑顺时针/逆时针等价性。
- 交换操作可选任意两位置，不限相邻。
- 需输出最少交换次数，不是最少相邻交换；计算时要找与目标排列的最大匹配循环以减交换。
- 输入行可能分多行给出排列，但总数为 N。

【解法提示（可选）】

- 枚举合法顺序的两种方向的所有 N 个旋转，求与当前排列的最少交换次数（= N - 已在位元素数的最大值, 或 N - 最大循环数）。选择最小值即可。\*\*\*
