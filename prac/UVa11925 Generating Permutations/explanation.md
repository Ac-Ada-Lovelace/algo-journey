# UVa11925 解题思路

## 关键理解

### 反向操作
- **操作1**：swap(arr[0], arr[1]) - 交换前两个
  - **反向**：swap(arr[0], arr[1]) - 仍然是交换（自逆）

- **操作2**：将arr[0]移到末尾
  - **反向**：将arr[n-1]移到开头

### 策略：从后向前归位

从目标排列开始，反向操作回到 [1,2,3,...,n]：

1. 处理最大的元素 n
   - 如果n已经在位置n-1（最后），跳过
   - 否则，将n移到位置n-1

2. 处理次大的元素 n-1
   - 在前n-1个元素中，将n-1移到位置n-2

3. 依此类推...

### 如何移动元素到末尾？

假设要把位置i的元素移到位置n-1：

```
如果 i == 0:
    执行 n-1 次反向操作2

如果 i == 1:
    执行 1 次反向操作1 (交换到位置0)
    执行 n-1 次反向操作2

如果 i >= 2:
    执行 i 次反向操作2 (移动到位置0或1)
    然后按照上面处理
```

## 样例3详细模拟

目标：4 2 3 1 → 变回 1 2 3 4

### 第一步：处理4（应该在位置3）
```
当前：4 2 3 1  (4在位置0)
策略：4在位置0，执行3次反向操作2

反向操作2: 1 4 2 3  (记录'2')
反向操作2: 3 1 4 2  (记录'2')
反向操作2: 2 3 1 4  (记录'2')  ← 4归位！

反向操作序列：222
```

### 第二步：处理3（在前3个元素中，应该在位置2）
```
当前：2 3 1  (3在位置1)
策略：3在位置1，先交换到位置0，再移到最后

反向操作1: 3 2 1  (记录'1')
反向操作2: 1 3 2  (记录'2')
反向操作2: 2 1 3  (记录'2')  ← 3归位！

反向操作序列：222 + 122 = 222122
```

### 第三步：处理2（在前2个元素中，应该在位置1）
```
当前：2 1  (2在位置0)
策略：2在位置0，执行1次反向操作2

反向操作2: 1 2  (记录'2')  ← 2归位！

反向操作序列：222122 + 2 = 2221222
```
