【题目概览】

- 题目定义了“正规括号序列”：空串为正规；若 S 正规，则 (S) 与 [S] 也正规；若 A、B 正规，则 AB 正规。给定只含 ()[] 的序列，需构造长度最短的正规括号序列，使原序列为其子序列（子序列定义：可按递增下标选出相同字符）。

【输入格式：逐句解释】

- 输入第一行是一个正整数，表示后续测试用例数量。
- 该行之后紧跟一行空行；相邻两个测试用例之间也各有一行空行。
- 每个测试用例：单独一行，包含至多 100 个括号字符（仅可能为 ‘(’、‘)’、‘[’、‘]’），行内无其他字符。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：测试用例数量 T
   - 含义：后续需要处理的括号串个数
   - 类型：正整数
   - 取值范围：题面未指定上限；至少为 1
   - 数据保证：独占一行
2. 第 2 行：空行
   - 含义：与 UVA 常见格式一致的分隔空行
   - 类型：空行
   - 取值范围：固定为空
   - 数据保证：题面明示存在
3. 随后每个测试用例：
   - 含义：给定的括号序列
   - 类型：字符串，仅含字符 ‘(’、‘)’、‘[’、‘]’
   - 取值范围：长度最多 100；题面未明确下限（可能为空行代表空串，仅作提醒）
   - 数据保证：一行内无其他字符
4. 测试用例间分隔：空行
   - 含义：两组输入之间有一行空行
   - 类型：空行
   - 数据保证：题面明示存在

多组输入：

- 是否多组：是，由首行 T 控制
- 每组格式：空行后跟一行括号串
- 终止条件：处理完 T 个用例
- 终止行是否需要处理：否，空行仅作分隔

隐含条件 / 数据保证：

- 括号串长度不超过 100（PDF 明示）。
- 括号字符集仅为四种括号符号（PDF 明示）。
- 空行仅作分隔，不属于括号串（依据 PDF 描述的空行安排）。

【输出格式】

- 对每个测试用例输出一行：任意一个满足条件的正规括号序列，且长度最小，并包含输入序列为其子序列。
- 相邻测试用例的输出之间也需以一行空行分隔。

【样例输入输出（完整引用 + 输入部分解释）】
Sample Input

```
1

([(]
```

样例解释：首行 1 表示一组用例；第二行为分隔的空行；第三行是给定括号序列 “([(]”。

Sample Output

```
()[()]
```

样例对应：输出为长度最短的合法括号序列，包含输入子序列。

【关键假设 / 陷阱】

- 输入与输出之间都要求保留空行分隔，缺失空行会导致格式错误。
- 括号串可能不正规，需补全最少括号并允许重排？（否，必须保持作为子序列，原字符顺序不可变。）
- 题面未禁止空串输入，若出现应输出空串本身即可（推测，根据“空串为正规”规则）。
- 仅四种括号字符有效，其他字符不会出现。

【解法提示（可选）】

- 典型做法是区间 DP：f[l][r] 表示闭区间最短解，枚举配对及拆分；重构输出需保存决策。
