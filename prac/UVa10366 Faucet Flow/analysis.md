# 样例2分析

## 输入
```
-3 3
4 3 2 1
```

## 结构

隔板位置和高度：
- 位置 -3，高度 4
- 位置 -1，高度 3
- 位置 1，高度 2
- 位置 3，高度 1

```
        水龙头↓ (x=0)
          |
    ╔══════════════════╗
    ║  |  |     |   |  ║  高度4
    ║  |  |     |   |  ║
    ║  |  |     |   |  ║  高度3
    ║  |  |     |      ║  高度2
    ║  |  |            ║  高度1
    ╚══════════════════╝
      -3 -1  0  1   3
       4  3     2   1
```

## 水流过程

### 初始状态
- 水从 x=0 倒入
- x=0 在区间 (-1, 1) 之间
- 区间宽度 = 2

### 步骤1：水位到达高度1
- 区间：(-1, 1)，宽度2
- 水位从 0 → 1
- 水量：1 × 2 = 2
- 总水量：2秒

### 步骤2：水位到达高度2（右边隔板）
- 区间：(-1, 1)，宽度2
- 水位从 1 → 2
- 水量：1 × 2 = 2
- 总水量：4秒
- **水溢出右边隔板（高度2），扩展到 (1, 3)**

### 步骤3：水位到达高度2（整个连通区域）
- 连通区间：(-1, 3)，宽度4
- 左侧区间 (-1, 1) 水位已经是 2
- 右侧区间 (1, 3) 需要填充到高度 2
  - 区间 (1, 3) 宽度 = 2
  - 水位从 0 → 2
  - 但是有隔板在高度1！

等等，我理解错了！

当水溢出隔板时，不是"扩展区间"，而是水可以流到另一边！

让我重新理解：**水的流动规律**：
1. 水在一个封闭区间内上升
2. 当水位达到某个隔板高度时，水溢出到相邻区间
3. 相邻区间开始接收水
4. 如果相邻区间水位较低，水会快速流入填充
5. 最终所有连通区域水位相同

这是一个**动态连通性**问题！
