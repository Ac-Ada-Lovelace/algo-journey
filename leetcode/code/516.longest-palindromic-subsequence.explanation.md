【题目概览】
给定字符串 s，求 s 中最长回文子序列的长度。

【函数输入：逐段解释】

1. 给定一个字符串 s。
2. 要求找出 s 的最长回文“子序列”的长度。
3. 子序列指从原序列删除若干（或不删）字符，保持剩余字符相对顺序不变得到的序列。

【输入格式（结构化摘要）——字段清单形式】
字段顺序：

1. 参数 s
   - 含义：输入字符串
   - 类型：string
   - 取值范围：1 <= s.length <= 1000；s 仅由小写英文字母组成
   - 数据保证：题面仅给出上述约束

隐含条件 / 数据保证：

- 题面未提供额外保证

【返回值 / 输出格式】
返回一个整数，表示字符串 s 的最长回文子序列的长度。

【样例（完整引用 + 参数解释）】
样例 1：

<pre>
Input: s = "bbbab"
Output: 4
Explanation: One possible longest palindromic subsequence is "bbbb".
</pre>

参数解释：s = "bbbab"。

样例 2：

<pre>
Input: s = "cbbd"
Output: 2
Explanation: One possible longest palindromic subsequence is "bb".
</pre>

参数解释：s = "cbbd"。

【关键假设 / 陷阱】

- 子序列保持原字符相对顺序，但不要求连续。
- 需要的是“最长回文子序列长度”，不是子串。
- 约束：1 <= s.length <= 1000；s 仅由小写英文字母组成。
