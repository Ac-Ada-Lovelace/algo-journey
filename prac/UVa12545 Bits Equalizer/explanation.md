【题目概览】

- 给定等长的两个非空字符串 S、T。S 由字符 ‘0’、‘1’、‘?’ 组成，T 仅含 ‘0’、‘1’。一次操作可以：1）把 S 中的 ‘0’ 改成 ‘1’；2）把 S 中的 ‘?’ 改成 ‘0’ 或 ‘1’；3）交换 S 中任意两个位置的字符。求将 S 变成 T 的最少操作次数，若无法转换则输出 -1。

【输入格式：逐句解释】

- 第一行是整数 C（C ≤ 200），表示测试用例数量。
- 每个测试用例包含两行：
  - 第一行是字符串 S，字符集为 ‘0’、‘1’、‘?’。
  - 第二行是字符串 T，字符集为 ‘0’、‘1’。
- 两个字符串等长且长度不超过 100；字符串均非空。

【输入格式（结构化摘要）——字段清单】

字段顺序：

1. 第 1 行：C
   - 含义：测试用例个数
   - 类型：整数
   - 取值范围：C ≤ 200
   - 数据保证：题面未给下界，含义为正整数个数（至少 1）
2. 每个用例的第 1 行：S
   - 含义：源字符串
   - 类型：仅含字符 ‘0’、‘1’、‘?’ 的字符串
   - 取值范围：长度 ≤ 100
   - 数据保证：非空；与对应 T 等长
3. 每个用例的第 2 行：T
   - 含义：目标字符串
   - 类型：仅含字符 ‘0’、‘1’ 的字符串
   - 取值范围：长度 ≤ 100
   - 特别说明：与对应 S 等长

多组输入：

- 是否多组：是，由 C 指定数量
- 每组格式：两行，先 S 后 T
- 终止条件：无单独终止标记，按 C 次读取
- 终止行是否需要处理：不适用

隐含条件 / 数据保证：

- S、T 等长且非空（题面明确）
- S 字符集含 0/1/?，T 仅含 0/1（题面明确）
- C ≤ 200，字符串长度 ≤ 100（题面明确）

【输出格式】

- 对每个测试用例输出一行，形如 “Case X: Y”。
- X 为用例编号，从 1 开始递增。
- Y 为将 S 转成 T 的最少操作数；若无法转换，输出 -1。

【样例输入输出（完整引用 + 输入部分解释）】

Sample Input

```
3
01??00
001010
01
10
110001
000000
```

Sample Output

```
Case 1: 3
Case 2: 1
Case 3: -1
```

样例说明：

- 用例 1：S=01??00，T=001010，最优需要 3 步（题面给出逐步示例：两次替换+一次交换）。
- 用例 2：S=01，T=10，1 次交换即可。
- 用例 3：S=110001，T=000000，因无法把 1 变 0，转换不可行，输出 -1。

【关键假设 / 陷阱】

- 允许的替换仅包括：0→1，?→0/1，不允许 1→0；若 T 中需要的 0 少于 S 中已有 1，则可能无解。
- 交换任意两位置计 1 次，可多次使用。
- 需输出最少操作数，存在不可达情况时输出 -1。
- 字符串等长这一条件是必需前提，输入已保证。

【解法提示（可选）】

- 统计位置差异：先用 ? 去匹配缺的 0/1；0→1 的替换次数确定后，剩余的 1/0 失配可通过交换配对，每对失配 1 次交换。若 1 需求不足导致多余 1 需变 0 则无解。\*\*\*
