【题目概览】

- 将 DNA 序列映射为二进制串（A/T→0，C/G→1），寻找长度至少为 L 的连续子串，使平均值（即 GC 比率对应的 0/1 平均）最大；若有多条平均值相同，选最短的；若仍有并列，选起始下标最小的。

【输入格式：逐句解释】

- 输入包含 T 组测试。第一行是整数 T，表示测试用例数。
- 每个测试用例两行：
  - 第一行：两个整数 n (1 ≤ n ≤ 100,000) 和 L (1 ≤ L ≤ 1,000)，依次为二进制序列长度与长度下界。
  - 第二行：一个长度为 n 的二进制字符串，字符为 0 或 1，表示序列。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：T
   - 含义：测试用例个数。
   - 类型：整数。
   - 取值范围：题面未给上限，由输入提供。
   - 数据保证：题面未给额外保证。

2. 每组第 1 行：n, L
   - 含义：序列长度 n；子序列长度下界 L。
   - 类型：正整数。
   - 取值范围：1 ≤ n ≤ 100,000；1 ≤ L ≤ 1,000。
   - 特别说明：以空格分隔。

3. 每组第 2 行：二进制字符串
   - 含义：长度为 n 的 0/1 序列。
   - 类型：字符串。
   - 取值范围：长度恰为 n，字符只能是 ‘0’ 或 ‘1’。
   - 特别说明：字符之间无空格。

多组输入：

- 是否多组：是，由首行 T 控制。
- 每组格式：两行，如上。
- 终止条件：读取完 T 组。
- 终止行是否需要处理：否。

隐含条件 / 数据保证：

- 目标子串必须连续，长度至少为 L。
- 比较顺序：先最大平均值；若并列，取长度最短；若仍并列，取起始下标最小。
- 下标在题面示例中以 1 为起点。

【输出格式】

- 对每个测试用例输出一行，包含两个整数：所求子序列的起始下标和结束下标（1-based）。

【样例输入输出（完整引用 + 输入部分解释）】
样例输入：

```
2
17 5
00101011011011010
20 4
11100111100111110000
```

输入解释：

- T = 2。
- 第 1 组：n = 17，L = 5，序列为 “00101011011011010”。
- 第 2 组：n = 20，L = 4，序列为 “11100111100111110000”。

样例输出：

```
7 11
6 9
```

- 分别为两组测试的最优子串起止下标。

【关键假设 / 陷阱】

- 子串必须连续且长度不少于 L。
- 平均值优先级最高，其次是长度最短，再其次是起始最小。
- n 可达 10^5、L 可达 10^3，需注意复杂度。
- 输入字符串无空格，注意按行读取。

【解法提示（可选）】

- 可二分平均值，用前缀和转换为“是否存在长度≥L 的子串使 (前缀差)≥0”，配合维护前缀最小值确定可行并记录最短、最左区间；或用滑动窗口/单调队列优化。
