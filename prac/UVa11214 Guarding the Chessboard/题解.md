# UVa11214 Guarding the Chessboard 题解

## 题目概述

给定一个 n×m 的棋盘,其中某些格子被标记为'X',要求用**最少的皇后**来守卫(攻击或占据)所有标记的格子。

- **棋盘大小**: 1 < n, m < 10 (最大9×9)
- **皇后的攻击范围**: 横、竖、斜线(8个方向)
- **皇后可以放在未标记的格子上**
- **目标**: 用最少的皇后覆盖所有'X'格子

## 解法对比

### 解法1: 线状态法 (luogu解法)

#### 核心思路
**把"覆盖点"的问题转化为"覆盖线"的问题**

#### 数据结构
```cpp
bool x[30], y[30], xpy[30], xmy[30];
```
- `x[i]`: 第i行是否还有未被覆盖的X
- `y[j]`: 第j列是否还有未被覆盖的X
- `xpy[i+j]`: 主对角线(i+j相同)是否还有未被覆盖的X
- `xmy[i-j+10]`: 副对角线(i-j相同,+10避免负数)是否还有未被覆盖的X

#### 初始化
```cpp
for(int i=1; i<=n; i++)
    for(int j=1; j<=m; j++)
        if(s[i][j-1]=='X'){
            ma[i][j]=1;      // 记录X的位置
            x[i]=1;          // 第i行有X
            y[j]=1;          // 第j列有X
            xpy[i+j]=1;      // i+j这条对角线有X
            xmy[i-j+10]=1;   // i-j这条对角线有X
        }
```

#### 关键剪枝
```cpp
// 只在能覆盖至少一条线的位置放皇后
if(x[i]==0 && y[j]==0 && xpy[i+j]==0 && xmy[i-j+10]==0)
    continue;
```

#### 终止条件
```cpp
if(num==l){  // 放了l个皇后
    // 检查是否所有X都被覆盖
    for(int i=1;i<=n;i++)
        for(int j=1;j<=m;j++)
            if(ma[i][j]==1)  // 如果是X
                // 且它的4条线都还没被覆盖
                if(x[i]==1 && y[j]==1 && xpy[i+j]==1 && xmy[i-j+10]==1)
                    return false;  // 失败
    return true;  // 成功
}
```

#### 优点
- 状态空间小(最多只有n+m+2n条线)
- 剪枝强(只在能覆盖至少一条线的位置放皇后)
- 代码简洁

### 解法2: 直接覆盖法 (luogu2解法) ⭐ 推荐

#### 核心思路
**直接维护每个X的覆盖状态 + IDA*剪枝**

这是最标准、最通用的IDA*模板写法!

#### 数据结构
```cpp
int a[15][15];  // a[i][j]=1 表示(i,j)是X
int b[15][15];  // b[i][j]=1 表示(i,j)已被覆盖
int ans;        // 当前还有多少个X未被覆盖
```

#### DFS参数
```cpp
bool dfs(int x, int y, int o1, int o2)
```
- `x`: 当前已放置的皇后数量
- `y`: 目标皇后数量(IDA*的深度限制)
- `o1, o2`: 上一个皇后的位置(i, j),用于剪枝避免重复

#### 终止条件
```cpp
if(x == y)  // 放了y个皇后
    return ans > 0 ? false : true;  // 检查是否还有未覆盖的X
```

#### 估价函数剪枝
```cpp
if(ceil(ans/1.0/(n+m-1+min(n,m)*2-2)) > y-x)
    return false;
```

**估价逻辑**:
- 分母 = 一个皇后最多能控制的线数
  - n条行 + m条列 - 1(去重)
  - + min(n,m)*2-2 条对角线(粗略估计)
- `ans/(线数)` = 乐观估计还需要多少个皇后
- 如果需要的 > 剩余深度,剪枝

#### 放置皇后核心代码
```cpp
for(i=o1; i<=n; i++){
    for(; j<=m; j++){
        vector<pair<int,int>> v;  // 记录本次新覆盖的X

        // 1. 覆盖同列
        for(int k=1; k<=n; k++)
            if(a[k][j]==1 && b[k][j]==0)
                b[k][j]=1, v.push_back({k,j});

        // 2. 覆盖同行
        for(int k=1; k<=m; k++)
            if(a[i][k]==1 && b[i][k]==0)
                b[i][k]=1, v.push_back({i,k});

        // 3. 覆盖主对角线 (i+j相同)
        for(int k=1; k<=min(i+j,n); k++)
            if(i+j-k>=1 && i+j-k<=m && a[k][i+j-k]==1 && b[k][i+j-k]==0)
                b[k][i+j-k]=1, v.push_back({k,i+j-k});

        // 4. 覆盖副对角线 (i-j相同)
        for(int k=1; k<=n; k++)
            if(k+j-i>=1 && k+j-i<=m && a[k][k+j-i]==1 && b[k][k+j-i]==0)
                b[k][k+j-i]=1, v.push_back({k,k+j-i});

        if(v.size() == 0) continue;  // 不能覆盖任何新X,跳过

        // 递归搜索
        ans -= v.size();
        if(dfs(x+1, y, i, j)) return true;

        // 回溯
        ans += v.size();
        for(auto [r, c] : v) b[r][c] = 0;
    }
    j = 1;  // 下一行从第1列开始
}
```

#### 迭代加深
```cpp
for(int i=0; i<=9; i++){  // 从0个皇后到9个皇后
    if(dfs(0, i, 1, 0)){
        printf("Case %lld: %lld\n", T, i);
        break;
    }
}
```

#### 优点
- **思路直接**: 直接维护哪些X被覆盖
- **剪枝清晰**: 只在能覆盖新X的位置放皇后
- **容易理解**: 不需要抽象转换
- **容易调试**: 可以打印b数组看覆盖情况
- **通用性强**: 适合各种覆盖问题

## 两种解法对比

| 方面 | 解法1 (线状态) | 解法2 (直接覆盖) ⭐ |
|------|----------------|---------------------|
| **抽象层次** | 高(用线代替点) | 低(直接操作点) |
| **代码长度** | 短 | 稍长 |
| **理解难度** | 需要思考 | 直观 |
| **效率** | 理论上更快(状态少) | 稍慢(需要扫描4个方向) |
| **通用性** | 适合这道题 | 更通用 |
| **推荐度** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ |

## 关键技巧总结

### 1. IDA*迭代加深
从小到大枚举皇后数量,找到最小解

### 2. 估价函数剪枝
乐观估计:假设每个皇后都能覆盖最多的X,如果仍然超过深度限制则剪枝

### 3. 避免重复搜索
从上一个皇后的位置继续搜索,避免生成相同配置

### 4. 贪心剪枝
只在能覆盖至少一个新X(或新线)的位置放皇后

## 复杂度分析

- **时间复杂度**: O(C(n×m, k)) × O(验证),其中k是皇后数量(≤5)
- **空间复杂度**: O(n×m)

由于棋盘小(≤9×9)且皇后数少(≤5),剪枝后搜索空间可接受。
