【题目概览】

- 设计一套能照亮会议厅的灯光系统，有 n 类不同功率的灯，每类灯需要相同电流而对应不同电压；每类灯有已知需求数量与单灯成本。
- 每类电压源可供无限数量的同电压灯使用，原本可以为每类灯各买一个对应电压源。
- 为节省成本，可以取消部分低电压源并改用更高电压的灯替代（绝不能用更低功率灯替换更高功率需求）。
- 目标是求完成设计的最小总成本（电压源成本 + 所用灯的成本）。

【输入格式：逐句解释】

- 每个测试用例以整数 n 开始，表示灯的类别数，范围 1 ≤ n ≤ 1000。
- 接下来 n 行，每行 4 个整数 V, K, C, L：
  - V (1 ≤ V ≤ 132000)：该类灯的电压额定值。
  - K (1 ≤ K ≤ 1000)：该电压源的成本（每个电压级别买一个电源即可供无限多灯）。
  - C (1 ≤ C ≤ 10)：该类灯单个的成本。
  - L (1 ≤ L ≤ 100)：该类灯所需数量。
- 输入以 n = 0 的测试用例结束，该终止用例不需处理。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：n
   - 含义：灯的类别数
   - 类型：整数
   - 取值范围：1 ≤ n ≤ 1000
   - 数据保证：n = 0 为结束标记，此行出现 0 时该用例不处理

2. 第 2 至 n+1 行：V K C L
   - 含义：一类灯的参数：电压、该电压源成本、单灯成本、需求数量
   - 类型：四个整数
   - 取值范围：1 ≤ V ≤ 132000；1 ≤ K ≤ 1000；1 ≤ C ≤ 10；1 ≤ L ≤ 100
   - 特别说明：每种电压源可供无限数量同电压灯；只能用更高电压/功率灯替换低电压灯，不能反向替换

多组输入：

- 是否多组：是
- 每组格式：如上，第 1 行 n，后接 n 行 V K C L
- 终止条件：读到 n = 0
- 终止行是否需要处理：否（n = 0 的整组不参与计算）

隐含条件 / 数据保证：

- 所有类别共用相同电流，需按对应电压供电；每种电压源数量上无限制（来自题面描述）。
- 替换策略仅允许用更高功率/电压等级灯取代较低的（题面明确）。

【输出格式】

- 对每个测试用例输出一行，包含完成系统设计的最小总成本的整数值。

【样例输入输出（完整引用 + 输入部分解释）】
样例输入：

```
3
100 500 10 20
120 600 8 16
220 400 7 18
0
```

样例输出：

```
778
```

输入行含义说明：

- `3`：共有 3 类灯。
- `100 500 10 20`：电压 100，电源成本 500，单灯成本 10，需要 20 盏。
- `120 600 8 16`：电压 120，电源成本 600，单灯成本 8，需要 16 盏。
- `220 400 7 18`：电压 220，电源成本 400，单灯成本 7，需要 18 盏。
- `0`：终止标记，不是测试用例。

【关键假设 / 陷阱】

- 只能用更高电压/功率灯替换低电压灯，反向替换非法（题面明确）。
- 购买某个电压源后可支撑无限数量的同电压灯，且只需为每个保留的电压等级购买一次电压源。
- 终止行 n = 0 不参与计算，不能误当作测试用例。
- 成本计算需包含保留的电压源成本与所选灯的成本之和。

【解法提示（可选）】

- 按电压升序排序后做区间动态规划：转移代表把一段类别合并到最高电压，成本为最高电压源 + 该段灯数×该段最高电压灯价。
- 状态 dp[i] 表示处理到第 i 类（排序后）的最小成本，枚举前驱分段求最优。
