【题目概览】
给定两个字符串 s1 和 s2，返回使两个字符串相等所需删除字符的 ASCII 值之和的最小值。

【函数输入：逐段解释】
1. 给定两个字符串 s1 和 s2。
2. 允许删除任意字符，使两个字符串最终相等。
3. 删除字符的代价为该字符的 ASCII 值，目标是最小化代价总和。

【输入格式（结构化摘要）——字段清单形式】
字段顺序：
1. 参数 s1
   - 含义：第一个字符串
   - 类型：string
   - 取值范围：1 <= s1.length <= 1000
   - 数据保证：s1 仅由小写英文字母组成

2. 参数 s2
   - 含义：第二个字符串
   - 类型：string
   - 取值范围：1 <= s2.length <= 1000
   - 数据保证：s2 仅由小写英文字母组成

隐含条件 / 数据保证：
- 题面未提供额外保证

【返回值 / 输出格式】
返回一个整数，表示使两个字符串相等所需删除字符的 ASCII 值之和的最小值。

【样例（完整引用 + 参数解释）】
样例 1：
<pre>
Input: s1 = "sea", s2 = "eat"
Output: 231
Explanation: Deleting "s" from "sea" adds the ASCII value of "s" (115) to the sum.
Deleting "t" from "eat" adds 116 to the sum.
At the end, both strings are equal, and 115 + 116 = 231 is the minimum sum possible to achieve this.
</pre>
参数解释：s1 = "sea", s2 = "eat"。

样例 2：
<pre>
Input: s1 = "delete", s2 = "leet"
Output: 403
Explanation: Deleting "dee" from "delete" to turn the string into "let",
adds 100[d] + 101[e] + 101[e] to the sum.
Deleting "e" from "leet" adds 101[e] to the sum.
At the end, both strings are equal to "let", and the answer is 100+101+101+101 = 403.
If instead we turned both strings into "lee" or "eet", we would get answers of 433 or 417, which are higher.
</pre>
参数解释：s1 = "delete", s2 = "leet"。

【关键假设 / 陷阱】
- 只能通过删除字符让两个字符串相等，代价为被删字符的 ASCII 值。
- 结果为最小可能的 ASCII 值之和。
- 约束：1 <= s1.length, s2.length <= 1000；均为小写英文字母。
