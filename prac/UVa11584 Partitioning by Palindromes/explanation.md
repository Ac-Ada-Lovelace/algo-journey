【题目概览】

- 给定若干由小写字母组成的字符串，需要把每个字符串划分成若干连续非空片段，使得每个片段都是回文，求最少需要多少个片段。

【输入格式：逐句解释】

- 输入以一个整数 n 开始，表示测试用例的数量。
- 每个测试用例占一行，包含 1 到 1000 个小写字母字符，行内没有空白符。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：n
   - 含义：测试用例数量
   - 类型：整数
   - 取值范围：题面未指定
   - 数据保证：题面未提供额外保证

2. 第 2 行到第 n+1 行：s
   - 含义：待划分的字符串
   - 类型：仅含小写字母的字符串
   - 取值范围：长度 1–1000
   - 数据保证：无空白符，只有小写字母

多组输入：

- 是否多组：是（共 n 组）
- 每组格式：单行字符串
- 终止条件：读满 n 行
- 终止行是否需要处理：是（第 n 行也是有效数据）

隐含条件 / 数据保证：

- 字符串仅包含小写字母（PDF 明确）。
- 字符串长度在 1 到 1000 之间（PDF 明确）。
- 其他限制（如 n 的范围）题面未说明。

【输出格式】

- 对每个测试用例输出一行，内容为将该字符串划分为若干回文片段所需的最小分组数。

【样例输入输出（完整引用 + 输入部分解释）】

样例输入：

```
3
racecar
fastcar
aaadbccb
```

样例输出：

```
1
7
3
```

输入解释：

- 共 3 组测试：
  - 第 1 组字符串为 `racecar`，本身是回文。
  - 第 2 组字符串为 `fastcar`，没有非平凡回文子串，需要拆成单字符。
  - 第 3 组字符串为 `aaadbccb`，可拆为 `aaa`、`d`、`bccb` 等回文片段。

【关键假设 / 陷阱】

- 字符串长度上限 1000，需注意算法复杂度；题面未给 n 的上限（可能需要针对较大 n 处理）。
- 仅有小写字母且无空白，读取整行即可；不要误读为包含空格或大小写混合。
- 输出每组一行，不要额外空行或前缀。

【解法提示（可选）】

- 预处理回文区间（如中心扩展或 DP），再用区间 DP 求最少切分数。
- 状态：f[i] 为前 i 个字符最少片段数，转移枚举以 i 结尾的回文子串。
- 时间可达 O(n^2)，在长度 1000 下可接受。
