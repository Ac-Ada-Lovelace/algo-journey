【题目概览】
- 给定一个不自交的简单多边形（按顺序给出顶点），需要对其进行三角剖分，并在所有三角剖分中使“最大三角形面积”最小，输出该最小化后的最大三角形面积。

【输入格式：逐句解释】
- 第一行：一个正整数 n，表示测试场景数量。
- 每个场景开头一行：正整数 m（2 < m < 50），为多边形顶点数。
- 接下来 m 行：按边界顺序给出顶点坐标，顺序可顺时针或逆时针，起点任意。
  - 每行两个整数 `x y`，满足 0 ≤ x ≤ 10000，0 ≤ y ≤ 10000。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：
1. 第 1 行：测试场景数量 n
   - 含义：后续要处理的多边形数量
   - 类型：正整数
   - 取值范围：题面未给上限
   - 数据保证：独占一行
2. 每个场景的第 1 行：顶点数 m
   - 含义：该简单多边形的顶点个数
   - 类型：整数
   - 取值范围：2 < m < 50
   - 数据保证：独占一行
3. 随后 m 行：顶点坐标
   - 含义：按多边形边界顺序给出的顶点
   - 类型：整数对 x y
   - 取值范围：0 ≤ x ≤ 10000，0 ≤ y ≤ 10000
   - 特别说明：顺序可顺时针或逆时针，起点任意；多边形不自交（简单多边形）。

多组输入：
- 是否多组：是，由首行 n 控制
- 每组格式：m，随后 m 行顶点
- 终止条件：读取完 n 个场景
- 终止行是否需要处理：否

隐含条件 / 数据保证：
- 多边形是简单多边形（不自交），题面明确说明。
- 三角剖分定义：选取 m-3 条互不相交的弦使多边形被划分成三角形。
- 顶点按边界顺序给出（顺/逆时针均可）。

【输出格式】
- 对每个场景输出一行：该多边形所有三角剖分中，最大三角形面积的最小可能值。
- 面积保留一位小数输出。

【样例输入输出（完整引用 + 输入部分解释）】
Sample Input
```
1
6
7 0
6 2
9 5
3 5
0 3
1 1
```
样例解释：1 个场景；多边形 6 个点，按给定顺序形成简单多边形。

Sample Output
```
9.0
```
样例对应：在所有三角剖分中，使最大三角形面积最小化后的最大值为 9.0。

【关键假设 / 陷阱】
- 必须输出一位小数，不能用整数或多位小数。
- 输入顶点顺序已按边界排列，无需重排；需按此顺序做三角剖分（多边形为简单多边形）。
- m 上限 49（严格小于 50）；顶点坐标非负且不超过 10000。
- 目标是“最小化最大三角形面积”而非最小化面积和。

【解法提示（可选）】
- 区间 DP：`dp[i][j]` 为顶点 i..j 形成子多边形的最优“最大三角形面积”，转移枚举划分点 k，三角面积取三点 (i,k,j)；答案 `dp[0][m-1]`。
