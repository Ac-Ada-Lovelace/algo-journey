【题目概览】
给定一个下标从 0 开始的整数数组 obstacles，长度为 n，obstacles[i] 表示第 i 个障碍的高度。对每个下标 i（0 到 n-1，含端点），要求在 0..i 的范围内选取若干障碍，必须包含第 i 个障碍，且保持原数组中的出现顺序，并且相邻障碍高度满足“非递减”（后一个高度大于或等于前一个）。返回长度为 n 的数组 ans，其中 ans[i] 是满足上述条件、且必须包含第 i 个障碍的最长障碍路线长度。

【函数输入：逐段解释】
题面给出一个 0 下标数组 obstacles，长度为 n，obstacles[i] 是第 i 个障碍的高度。
对每个 i（0 到 n-1，含端点），只能在下标 0..i 之间选障碍，必须包含第 i 个障碍，选出的障碍保持原顺序，且相邻高度必须相同或更高。
要求返回数组 ans，ans[i] 是对应 i 的最长障碍路线长度。

【输入格式（结构化摘要）——字段清单形式】
字段顺序：

1. 参数：obstacles
   - 含义：障碍高度数组，obstacles[i] 为第 i 个障碍的高度
   - 类型：integer[]
   - 取值范围：1 <= obstacles[i] <= 10^7
   - 数据保证：n == obstacles.length，1 <= n <= 10^5

多组输入：

- 是否多组：否（函数式输入）
- 每组格式：不适用
- 终止条件：不适用
- 终止行是否需要处理：不适用

隐含条件 / 数据保证：

- 题面明确给出：下标从 0 开始
- 题面明确给出：必须包含第 i 个障碍
- 题面明确给出：相邻障碍高度为“相同或更高”

【返回值 / 输出格式】
返回长度为 n 的数组 ans，其中 ans[i] 表示在下标 0..i 范围内、必须包含第 i 个障碍、保持原顺序且高度非递减的最长障碍路线长度。

【样例（完整引用 + 参数解释）】
示例 1：
Input: obstacles = [1,2,3,2]
Output: [1,2,3,3]
Explanation: The longest valid obstacle course at each position is:

- i = 0: [1], [1] has length 1.
- i = 1: [1,2], [1,2] has length 2.

- i = 2: [1,2,3], [1,2,3] has length 3.
- i = 3: [1,2,3,2], [1,2,2] has length 3.
  参数解释：obstacles = [1,2,3,2]，返回每个位置 i 的最长有效障碍路线长度。

示例 2：
Input: obstacles = [2,2,1]
Output: [1,2,1]
Explanation: The longest valid obstacle course at each position is:

- i = 0: [2], [2] has length 1.
- i = 1: [2,2], [2,2] has length 2.
- i = 2: [2,2,1], [1] has length 1.
  参数解释：obstacles = [2,2,1]，返回每个位置 i 的最长有效障碍路线长度。

示例 3：
Input: obstacles = [3,1,5,6,4,2]
Output: [1,1,2,3,2,2]
Explanation: The longest valid obstacle course at each position is:

- i = 0: [3], [3] has length 1.
- i = 1: [3,1], [1] has length 1.
- i = 2: [3,1,5], [3,5] has length 2. [1,5] is also valid.
- i = 3: [3,1,5,6], [3,5,6] has length 3. [1,5,6] is also valid.
- i = 4: [3,1,5,6,4], [3,4] has length 2. [1,4] is also valid.
- i = 5: [3,1,5,6,4,2], [1,2] has length 2.
  参数解释：obstacles = [3,1,5,6,4,2]，返回每个位置 i 的最长有效障碍路线长度。
