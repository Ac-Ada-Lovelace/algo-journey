【题目概览】
- 给定平面上 n 个点（x 坐标各不相同且已按 x 递增给出）。John 的策略：从最左点出发，严格按 x 递增依次走到最右点，再严格按 x 递减走回起点，形成闭合回路。求在遵循此策略下，连接所有点的最短闭合路径长度。

【输入格式：逐句解释】
- 输入文件包含若干数据集，每个数据集描述一组点。
- 对于每个数据集，首先给出整数 n（点的数量）。
- 随后给出 n 个点坐标，按 x 坐标递增顺序提供，每个点是一个平面坐标对 pi = <xi, yi>。
- 输入中的空白可以自由出现；输入数据保证正确。

【输入格式（结构化摘要）】

字段顺序：
1. 每个数据集第 1 行：n  
   - 含义：点的数量  
   - 类型：整数  
   - 取值范围：题面未说明上限，下限为正；当存在数据集时 n>0  
   - 数据保证：点的 x 坐标两两不同
2. 接下来的 n 行：xi yi  
   - 含义：第 i 个点的平面坐标  
   - 类型：实数对  
   - 取值范围：题面未限定  
   - 数据保证：按 x 坐标递增给出；空白任意

多组输入：
- 是否多组：是
- 每组格式：如上两步
- 终止条件：文件结束（EOF）
- 终止行是否需要处理：否

隐含条件 / 数据保证：
- x 坐标各不相同（“distinct x-coordinates”）。
- 路径顺序被限定：先严格从最左到最右，再严格从最右返回起点；不允许打乱先后。
- 输入保证正确，无需自行验证合法性。

【输出格式】
- 对每个数据集输出一行，从行首开始打印闭合路径的最短长度，采用浮点数格式，保留两位小数。

【样例输入输出（完整引用 + 输入部分解释）】
Sample Input：
```
3
1 1
2 3
3 1
4
1 1
2 3
3 1
4 2
```
- 数据集 1：n=3，点依次为 (1,1), (2,3), (3,1)。
- 数据集 2：n=4，点依次为 (1,1), (2,3), (3,1), (4,2)。

Sample Output：
```
6.47
7.89
```
- 分别对应两组数据的最短闭合路径长度（两位小数）。

【关键假设 / 陷阱】
- 走向必须遵守“先左到右，再右到左”的顺序；过程中不能再往右插入返回后的点。
- x 坐标均不同，输入已按 x 递增给出，可直接使用此顺序。
- 输出格式需要固定两位小数。

【解法提示（可选）】
- 可用“双端点”动态规划（bitonic tour）：dp[i][j] 表示已覆盖前缀到 max(i,j)，端点在 i、j 的最短路长，转移使用欧几里得距离，最终两端在最右点时取最小值。
