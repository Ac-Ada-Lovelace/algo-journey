【题目概览】
给定一个由 k 个升序链表组成的数组 lists，需要将所有链表合并成一个升序链表并返回。

【函数输入：逐段解释】
题面说明：给你一个链表数组 lists，其中每个链表都按升序排列。需要把所有链表合并为一个升序链表并返回。

【输入格式（结构化摘要）——字段清单形式】
字段顺序：
1. 参数 lists
   - 含义：包含 k 个链表的数组，每个链表为升序
   - 类型：ListNode[]
   - 取值范围：k == lists.length；0 <= k <= 10^4；0 <= lists[i].length <= 500；
     -10^4 <= lists[i][j] <= 10^4
   - 数据保证：lists[i] 为升序；所有 lists[i].length 之和不超过 10^4

多组输入：
- 是否多组：否（函数单次调用）
- 每组格式：不适用
- 终止条件：不适用
- 终止行是否需要处理：不适用

隐含条件 / 数据保证：
- k == lists.length
- lists[i] 已按升序排列
- 所有链表长度之和不超过 10^4

【返回值 / 输出格式】
返回合并后的升序链表（类型：ListNode）。当 lists 为空或所有链表为空时，返回空链表。

【样例（完整引用 + 参数解释）】
Example 1:
```
Input: lists = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]
Explanation: The linked-lists are:
[
  1->4->5,
  1->3->4,
  2->6
]
merging them into one sorted linked list:
1->1->2->3->4->4->5->6
```
样例 1 输入解释：
- lists 包含 3 个升序链表，分别为 [1,4,5]、[1,3,4]、[2,6]。

Example 2:
```
Input: lists = []
Output: []
```
样例 2 输入解释：
- lists 为空数组。

Example 3:
```
Input: lists = [[]]
Output: []
```
样例 3 输入解释：
- lists 含 1 个空链表。

【关键假设 / 陷阱】
- lists[i] 已按升序排列（题面保证）
- lists 可能为空，或包含空链表
- 链表节点值范围为 [-10^4, 10^4]
- 所有链表长度之和不超过 10^4

【解法提示（可选）】
- 可用最小堆逐步取最小节点，或分治两两合并。
