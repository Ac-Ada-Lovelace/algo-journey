【题目概览】

- 两条车道各有一串车辆颜色（每车用单个大写字母表示），相邻车辆间距为 1；两条车道需合并成单车道（保持各自车道内的相对顺序），合并后定义每种颜色的“色长”为该颜色最左与最右车辆位置差。求在所有合法合并方式中，使所有颜色色长之和最小的合并方案对应的最小和。

【输入格式：逐句解释】

- 输入第一行是整数 T，表示测试用例数量。
- 每个测试用例包含两行：
  - 第一行长度为 n（1 ≤ n ≤ 5000）的字符串，表示车道 1 的颜色序列。
  - 第二行长度为 m（1 ≤ m ≤ 5000）的字符串，表示车道 2 的颜色序列。
- 颜色用英文大写字母表示，颜色总数不超过 26 种。

【输入格式（结构化摘要）——字段清单形式】

字段顺序：

1. 第 1 行：T
   - 含义：测试用例数量
   - 类型：整数
   - 取值范围：题面未指定
   - 数据保证：题面未提供额外保证

2. 第 2 行（每组第 1 行）：s1
   - 含义：车道 1 的颜色字符串
   - 类型：仅含大写字母的字符串
   - 取值范围：长度 n，1 ≤ n ≤ 5000
   - 特别说明：保持原相对顺序在合并后不可改变

3. 第 3 行（每组第 2 行）：s2
   - 含义：车道 2 的颜色字符串
   - 类型：仅含大写字母的字符串
   - 取值范围：长度 m，1 ≤ m ≤ 5000
   - 特别说明：保持原相对顺序在合并后不可改变

多组输入：

- 是否多组：是（共 T 组）
- 每组格式：两行字符串 s1、s2
- 终止条件：读满 T 组
- 终止行是否需要处理：是（每组两行均为有效数据）

隐含条件 / 数据保证：

- 颜色字母均为大写英文字母（PDF 明确），颜色种类数 ≤ 26。
- 两条车道分别的顺序必须在合并中保持（PDF 场景与图示隐含）。
- 相邻车辆距离视为 1，合并后位置按合并序列的索引确定（PDF 场景隐含）。
- T 的范围题面未说明。

【输出格式】

- 对每个测试用例输出一行，内容为在所有合法合并方案中使总色长最小的值。无额外空格或前缀。

【样例输入输出（完整引用 + 输入部分解释）】

样例输入：

```
2
AAABBCY
ABBBCDEEY
GBBY
YRRGB
```

样例输出：

```
10
12
```

输入解释：

- 共 2 组测试。
  - 第 1 组：车道 1 为 `AAABBCY`，车道 2 为 `ABBBCDEEY`。
  - 第 2 组：车道 1 为 `GBBY`，车道 2 为 `YRRGB`。  
    合并需保持各自序列内部顺序，目标是最小化合并后各颜色的色长总和。

【关键假设 / 陷阱】

- 合并必须保持各自车道内顺序，只能交错，不可重排或反向。
- 色长定义为 max 位置 − min 位置（间距单位 1），单色只出现一次时色长为 0。
- 颜色种类 ≤ 26，可用于状态压缩或预处理；但 n、m 可达 5000，需要 O(nm) 或更优的算法。
- T 未给范围，需按多组数据处理；注意累计读取两行字符串作为一组。
- 输出严格一行一个值，勿额外空行。
 
【解法提示（可选）】

- 典型做法：二维 DP 交错合并，维护当前已放置前缀下各颜色的首次/末次出现位置增量，转移代价只与新放入字符颜色的首次/末次是否跨越前缀长度相关；可预处理两串每色首次/末次出现位置。
- 另一思路：区分“首次出现”和“最后出现”对色长的贡献，利用增量代价实现 O(nm) DP。
- 空间可滚动优化；需注意 5000×5000 规模时的内存与常数。
