# 巨人与鬼问题（质子流版本）- 分治法详解

## 问题本质

这是一个**平面点集无交叉完美匹配**问题。

给定 n 个巨人和 n 个鬼的坐标，要找到一种配对方案，使得所有连线不相交。

## 核心算法：排序法（最简单）

### 算法思想

**定理**：将巨人和鬼分别按 x 坐标（或 y 坐标）排序后按顺序配对，得到的匹配一定是无交叉的。

**证明**：
假设按 x 坐标排序后：
- 巨人序列：G1, G2, ..., Gn（G1.x ≤ G2.x ≤ ... ≤ Gn.x）
- 鬼序列：g1, g2, ..., gn（g1.x ≤ g2.x ≤ ... ≤ gn.x）

配对方案：Gi ↔ gi (i = 1, 2, ..., n)

**反证法**：
假设存在两条线段 (Gi, gi) 和 (Gj, gj) 相交，不失一般性设 i < j。

由排序可知：
- Gi.x ≤ Gj.x
- gi.x ≤ gj.x

两条线段相交意味着存在交点 P，则：
- P.x > min(Gi.x, gi.x)
- P.x < max(Gi.x, gi.x)
- P.x > min(Gj.x, gj.x)
- P.x < max(Gj.x, gj.x)

但由于 Gi.x ≤ Gj.x 且 gi.x ≤ gj.x，线段 (Gi, gi) 的 x 范围完全在线段 (Gj, gj) 的左侧（或至多部分重叠但端点顺序一致），因此不可能相交。

矛盾！证毕。■

### 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    double x, y;
    int id;  // 原始编号
};

bool cmp_x(const Point& a, const Point& b) {
    return a.x < b.x || (a.x == b.x && a.y < b.y);
}

int main() {
    int n;
    cin >> n;

    vector<Point> giants(n), ghosts(n);

    // 读入巨人坐标
    for (int i = 0; i < n; i++) {
        cin >> giants[i].x >> giants[i].y;
        giants[i].id = i + 1;
    }

    // 读入鬼坐标
    for (int i = 0; i < n; i++) {
        cin >> ghosts[i].x >> ghosts[i].y;
        ghosts[i].id = i + 1;
    }

    // 按 x 坐标排序
    sort(giants.begin(), giants.end(), cmp_x);
    sort(ghosts.begin(), ghosts.end(), cmp_x);

    // 输出配对方案
    vector<int> match(n + 1);  // match[i] = 第 i 个巨人配对的鬼
    for (int i = 0; i < n; i++) {
        match[giants[i].id] = ghosts[i].id;
    }

    for (int i = 1; i <= n; i++) {
        cout << match[i] << "\n";
    }

    return 0;
}
```

**时间复杂度**：O(n log n)（排序）

## 进阶算法：递归分治法

### 算法思想

1. **递归基**：n=1 时，唯一的巨人配对唯一的鬼
2. **分治步骤**：
   - 找到一条竖直线 x = m（中位数），将平面分为左右两部分
   - 统计左边有 kG 个巨人，kg 个鬼
   - 如果 kG = kg，完美！左边的巨人只能配左边的鬼，递归处理
   - 如果 kG ≠ kg，需要调整分割线或使用更复杂的策略

### 简化版本：强制平衡分割

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Point {
    double x, y;
    int id;
};

vector<Point> giants, ghosts;
vector<int> match;

void solve(vector<int> g_ids, vector<int> d_ids) {
    int n = g_ids.size();
    if (n == 0) return;
    if (n == 1) {
        match[g_ids[0]] = d_ids[0];
        return;
    }

    // 按 x 坐标排序
    sort(g_ids.begin(), g_ids.end(), [](int a, int b) {
        return giants[a].x < giants[b].x;
    });
    sort(d_ids.begin(), d_ids.end(), [](int a, int b) {
        return ghosts[a].x < ghosts[b].x;
    });

    // 分为两半
    int half = n / 2;
    vector<int> left_g(g_ids.begin(), g_ids.begin() + half);
    vector<int> right_g(g_ids.begin() + half, g_ids.end());
    vector<int> left_d(d_ids.begin(), d_ids.begin() + half);
    vector<int> right_d(d_ids.begin() + half, d_ids.end());

    // 递归处理
    solve(left_g, left_d);
    solve(right_g, right_d);
}

int main() {
    int n;
    cin >> n;

    giants.resize(n);
    ghosts.resize(n);
    match.resize(n);

    vector<int> g_ids, d_ids;
    for (int i = 0; i < n; i++) {
        cin >> giants[i].x >> giants[i].y;
        giants[i].id = i;
        g_ids.push_back(i);
    }

    for (int i = 0; i < n; i++) {
        cin >> ghosts[i].x >> ghosts[i].y;
        ghosts[i].id = i;
        d_ids.push_back(i);
    }

    solve(g_ids, d_ids);

    for (int i = 0; i < n; i++) {
        cout << match[i] + 1 << "\n";  // 输出编号从 1 开始
    }

    return 0;
}
```

**时间复杂度**：T(n) = 2T(n/2) + O(n log n) = O(n log² n)

## 关键引理与证明

### 引理1：排序法的正确性

**已在上面证明**

### 引理2：总存在无交叉匹配

**证明**：
对于任意 n 个巨人和 n 个鬼（无三点共线），总是存在一种无交叉的完美匹配。

**构造性证明**：
排序法给出了一种构造方案，因此存在性得证。■

### 引理3：分治法的正确性

如果按 x 坐标排序后将点集分为两半：
- 左半部分：前 k 个巨人和前 k 个鬼
- 右半部分：后 n-k 个巨人和后 n-k 个鬼

则左半部分的配对不会与右半部分的配对交叉。

**证明**：
左半部分所有点的 x 坐标 ≤ 右半部分所有点的 x 坐标（或至多相等）。
因此左半部分的任意线段不可能与右半部分的任意线段相交。■

## 扩展问题

### 1. 最短总距离的无交叉匹配

**问题**：在所有无交叉匹配中，找到总距离最小的那个。

**解法**：
- 动态规划（按 x 坐标排序后，DP 状态表示前 i 个巨人和前 i 个鬼的最优匹配）
- 时间复杂度：O(n²) 或 O(n³)

### 2. 判断两条线段是否相交

**工具函数**：
```cpp
struct Segment {
    Point p1, p2;
};

// 计算叉积
double cross(Point O, Point A, Point B) {
    return (A.x - O.x) * (B.y - O.y) - (A.y - O.y) * (B.x - O.x);
}

// 判断线段 AB 和 CD 是否相交（不包括端点重合）
bool segments_intersect(Segment s1, Segment s2) {
    Point A = s1.p1, B = s1.p2, C = s2.p1, D = s2.p2;

    double d1 = cross(C, D, A);
    double d2 = cross(C, D, B);
    double d3 = cross(A, B, C);
    double d4 = cross(A, B, D);

    if (d1 * d2 < 0 && d3 * d4 < 0) return true;  // 相交
    return false;  // 不相交或共线
}
```

## 总结

| 方法 | 时间复杂度 | 空间复杂度 | 实现难度 |
|------|-----------|-----------|---------|
| 排序法 | O(n log n) | O(n) | ⭐ 简单 |
| 分治法 | O(n log² n) | O(n log n) | ⭐⭐ 中等 |
| 凸包法 | O(n² log n) | O(n) | ⭐⭐⭐ 困难 |

**推荐使用排序法**：代码简洁，效率高，易于理解。

**关键点**：
1. 按 x 坐标排序后顺序配对，保证无交叉
2. 排序法是构造性证明的体现
3. 分治法体现了递归思想，但实现复杂度更高

这个问题是**计算几何 + 分治**的经典结合，非常优美！
