【题目概览】
给定一个整数 n，返回由 1 到 n 的互不相同的 n 个值构成的、结构不同的二叉搜索树（BST）的数量。题面含有图片示意，图片略去，需参考原题。

【函数输入：逐段解释】
- 给定整数 n。
- 需要返回由 1 到 n 的唯一值组成且结构不同的 BST 的数量。

【输入格式（结构化摘要）】
字段顺序：
1. 参数 n
   - 含义：节点数量，同时节点取值为 1 到 n 的互不相同整数
   - 类型：integer
   - 取值范围：1 <= n <= 19
   - 数据保证：题面未提供额外保证

多组输入：
- 是否多组：否
- 每组格式：不适用（函数式输入）
- 终止条件：不适用
- 终止行是否需要处理：不适用

隐含条件 / 数据保证：
- 节点值为 1 到 n，且互不相同

【返回值 / 输出格式】
返回一个整数，表示满足题意的 BST 的种数。

【样例（完整引用 + 参数解释）】
示例 1：
Input: n = 3
Output: 5

- 参数解释：n = 3。

示例 2：
Input: n = 1
Output: 1

- 参数解释：n = 1。

【关键假设 / 陷阱】
- 题目要求的是“结构不同”的 BST 数量。
- 取值范围仅给出 1 <= n <= 19。
- 题面包含图片示意，图片略去，需参考原题。

【解法提示（可选）】
- 可考虑用动态规划按节点数递推，或用卡特兰数性质。
